Metric catalogue¶

Every metric this build can measure: 172 definitions, generated from the MetricDef each provider publishes. A scenario selects metrics with its metrics: list (Metrics and outputs); each section below says which selection installs its metrics. Visibility gt means the metric is computed from ground truth that no node could observe, node that a node could compute it from what it received, and node-and-gt that it joins both. A health band, where a metric has one, is what v2xw compare and the Studio judge a value against.

Reading a row

Aggregation is how observations in a window are reduced. Min samples is the count below which a window reports insufficient instead of a value. Does not account for is what the definition deliberately leaves out.

envelope_overhead ratio ratio: envelope bytes / payload bytes node Security envelope bytes divided by application payload bytes, over the window

frag_content_loss_predicted ratio ratio: Σ Σ_i w_i p_i / fragmented SDUs attempted gt The content loss the independent-loss formula predicts from each fragment's PHY success probability, weighted by its share of the payload

frag_sdu_loss_independent ratio ratio: Σ (1 − (1 − p̂)^n_g) / fragmented SDUs attempted gt The SDU loss if every fragment were lost independently at the window's own measured per-fragment loss rate p̂ (frag_fragment_loss): the textbook 1 − (1 − p)^n
frag_sdu_loss_predicted ratio ratio: Σ (1 − Π (1 − p_i)) / fragmented SDUs attempted gt The SDU loss the independent-loss formula predicts from each fragment's PHY success probability at that receiver, if fragments were lost independently
full_cert_share ratio ratio: messages carrying a full certificate / all messages node The certificate attachment rate: messages whose signer identifier is a full certificate rather than a digest, divided by all messages
goodput B/s rate node Application payload bytes delivered to receivers' applications (node.rx), divided by the window's length
half_duplex_rate ratio ratio: attempts lost to half duplex / attempts resolved node The fraction of resolved reception attempts lost because the receiver was itself transmitting
headway_distance m distribution gt Distance headway: the difference of lane positions between a follower and its leader
headway_time s distribution gt Time headway: the gap to the leader divided by the follower's speed
latency_stage ms distribution node The time each delivered message spent in one stage of its journey
latency_stage_share ratio ratio: Σ time in this stage / Σ end-to-end latency node The share of the total end-to-end delay spent in one stage: the stage's summed duration over the summed latency of the same messages
latency_trace_rejected count count node Traces in the window that were not a valid decomposition of their message's latency (a gap, an overlap or a negative stage)

mac_access_delay ms distribution node Channel-access delay per transmitted frame: from the frame reaching the MAC (its signature complete) to its preamble going on the air — AIFS, backoff and deferral to a busy medium
mac_drops count count node Frames the MAC refused in the window: a full access-category queue or a frame over the MSDU cap
mac_queue_depth count distribution node Frames waiting in a node's EDCA access-category queues, at each MAC report, across nodes
mean_speed m/s mean gt The space-mean speed, q / k — not the time-mean speed, which is 6–12 % higher on a mixed-speed signalised dataset (Wardrop 1952)
nar ratio ratio: neighbours within R heard within T / neighbours within R node-and-gt Neighbourhood awareness ratio: of the vehicles truly within R metres of each equipped vehicle, the fraction it has received a message from in the last second
net_header_overhead ratio ratio: Σ network and transport header octets / Σ octets on the air node The share of the octets on the air that are the network and transport header: WSMP for the US stack, GeoNetworking plus BTP for the European one
offered_load bit/s rate node PSDU bits every node handed to its MAC in the window, whatever became of them, per second — network-wide
p2pcd_requests 1/s rate node Peer-to-peer certificate distribution requests per second, all nodes: signed SPDUs carrying a learning request for a certificate the sender could not resolve, out-of-band (p2pcdLearningRequest) or inline (inlineP2pcdRequest), IEEE 1609.2-2022 clause 8
pdr ratio ratio: receivers within range that decoded the frame / receivers within range gt Packet reception ratio (3GPP TR 36.885 §A.2.1.4): of the equipped receivers truly within range of each frame, the fraction that decoded it
pdr_all_pairs ratio ratio: received frames / evaluated receptions node-and-gt Received frames divided by every reception the engine evaluated: every pair within its candidate range, however far and whatever stands between them, per 25 m distance bin
pdr_by_cause ratio ratio: losses with this cause / all losses node The share of losses attributable to each loss cause
ped_conflicts count count gt Vehicle-pedestrian approaches whose time to collision fell below 3 s, each approach counted once
ped_midblock_share 1 mean gt The share of pedestrian samples off every lane: time spent crossing mid-block, away from any crosswalk
ped_near_misses count count gt Of the vehicle-pedestrian conflicts, those whose time to collision fell below 1.5 s
ped_ttc s distribution gt The time to collision of every vehicle-pedestrian pair-step below 10 s: a pedestrian walking across a moving vehicle's heading inside its swept width
ped_wait s distribution gt Pedestrian delay: the length of each standing episode (below 0.2 m/s) that ended in the window — at a kerb waiting for walk or a gap, mostly
per ratio ratio: receivers within range that did not decode the frame / receivers within range gt The complement of the headline pdr, over the same census within 300 m
pet s distribution gt Post-encroachment time: the interval between one actor leaving a position and a different actor arriving at it, resolved to cells of pet_cell_m
pir s distribution node-and-gt Packet inter-reception time: the gap between successive receptions from the same transmitter at the same receiver
revocation_latency_stage s distribution public The time between consecutive emitted stages of one revocation
security_overhead ratio ratio: Σ envelope octets / Σ octets on the air node The share of the octets on the air that are the security envelope — headers, signer identifier (certificate or digest) and signature — over the frames whose payload/envelope split is known
speed m/s distribution gt The distribution of sampled actor speeds over the window
time_to_decision s distribution node-and-gt Attack onset to the authority's decision about the attacker
time_to_detect s distribution node-and-gt Attack onset to the first correct report about the attacker at the authority

unverified_ratio ratio ratio: delivered without verification / delivered node Messages delivered to applications without verification, divided by messages delivered
verify_cost ms distribution node The per-task verification cost, from the primitive's cost table for the node's hardware profile (modeled mode) or measured (real mode)
verify_queue_depth count distribution node The verification queue's depth, sampled when a task is enqueued
verify_rate 1/s rate node Verifications completed per second, per cryptographic primitive
verify_wait ms distribution node Enqueue to start of verification

The distribution of sampled actor accelerations over the window.

Field Value
Unit m/s²
Aggregation distribution
Visibility gt
Dimensions t
Grid (quantum) 0.001
Min samples 30
Source assumption (this engine's own definition, no external source): traffic and safety metrics (code)

Does not account for:

  • the same time-weighting bias as speed
  • jerk, which the kinematics channel does not carry

air_bytes_per_payload_byte¶

Octets on the air per octet of application payload: how many bytes the air carries for each byte the application wanted to send.

Field Value
Unit B/B
Aggregation ratio: Σ octets on the air / Σ application payload octets
Visibility node
Dimensions t, msg_type
Grid (quantum) 0.0001
Min samples 1
Source assumption (this engine's own definition, no external source): the frame's layers and their sizes (code)

Does not account for:

  • frames with no payload/envelope split
  • the PHY preamble and tail, which are air time

airtime_per_node¶

Transmitted air time per node, divided by the window's length. With no dimension, the mean over the nodes that transmitted in the window.

Field Value
Unit ms/s
Aggregation rate
Visibility node
Dimensions t, node
Grid (quantum) 0.001
Min samples 1
Source assumption (this engine's own definition, no external source): radio and network metric catalog (code)
Better lower (standard basis)
Healthy within the 1 % duty cycle the relaxed DCC state allows
Caution 10.0: above 10 ms/s: more than the relaxed DCC state's 1 % duty cycle
Unhealthy 30.0: above 30 ms/s: past the 3 % per-station duty-cycle ceiling
Band source ETSI TS 102 687 V1.2.1 reactive DCC Relaxed state (T_on 1 ms per T_off 100 ms, 1 %); EN 302 571 / TS 102 687 adaptive δ_max 0.03 (3 % = 30 ms/s)

Does not account for:

  • receive-side occupancy
