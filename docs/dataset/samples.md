# V2X-SCMS-MBD mini release: samples

Generated by `tools/dataset/samples_doc.py` from the assembled release published as [akzaidan/v2x-scms-mbd-mini](https://huggingface.co/datasets/akzaidan/v2x-scms-mbd-mini). Every value below is a real row of that release.

## What it is

1 simulated run of 75 s, 60 vehicles, on a procedural street grid with the US SCMS in the loop. Each run is published from three sides: what each vehicle's OBU saw (`local/`), what the Misbehavior Authority saw (`global/`), and the ground truth (`truth/`), kept apart so no label sits next to a feature. Splits are per run: train: s01 (one split: no validation or test run, nothing held out).
