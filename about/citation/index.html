Citation and licence¶

How to cite¶

V2X World is written by Ahmed Zaidan (ORCID 0009-0009-4590-7996). The repository's CITATION.cff is the citation record (GitHub's "Cite this repository" button reads it). Its current values:

Field Value
title V2X World
author Ahmed Zaidan (0009-0009-4590-7996)
version 0.1.0
licence Apache-2.0
type software
keywords V2X, connected vehicles, SCMS, IEEE 1609.2, misbehavior detection, misbehavior authority, vehicular PKI, simulation
repository https://github.com/ak3zaidan/V2X-World
website https://ak3zaidan.github.io/V2X-World/

To cite the software:

@software{zaidan_v2xworld,
  title   = {{V2X World}},
  author  = {Zaidan, Ahmed},
  version = {0.1.0},
  year    = {2026},
  license = {Apache-2.0},
  url     = {https://github.com/ak3zaidan/V2X-World}
}

A paper describing the simulator is in preparation (arXiv:XXXX.XXXXX, a placeholder); the entry below will be filled in when it is available:

@misc{zaidan_v2xworld_paper,
  title         = {TODO: paper title},
  author        = {Zaidan, Ahmed},
  year          = {TODO},
  eprint        = {XXXX.XXXXX},
  archivePrefix = {arXiv},
  url           = {https://arxiv.org/abs/XXXX.XXXXX}
}

The V2X-World dataset on Hugging Face is licensed CC BY 4.0, which requires attribution: cite it with the software entry above (or the paper, once it is out) and name the dataset release you used.

For a result, also report what makes the run reproducible: the scenario file (or its scenario_hash), the seed, the engine's build_hash and git_commit, and the content_digest of the recording, all in the run's manifest.json and run-report.json (Recording format). Cite the models' sources as their cards give them (Standards and references).

Each PROVENANCE.md pins the upstream commit or tag, the fetch date and every file's sha256. The build reads the files as committed; none may be edited.

Not in the repository

  • SAE J2735 ASN.1: its licence forbids redistribution; the engine's J2735 codecs are hand-written. third_party/asn1/j2735/ is git-ignored.
  • SCMS Manager CTL, chain and elector files: "All Rights Reserved" with no licence, so tools/scms-artefacts/fetch.py downloads them into the git-ignored third_party/scms-artefacts/files/ and checks their published fingerprints.
  • Licensed test vectors (IEEE 1609.2a, CAMP, NIST CAVP, RFC 4231): only the values needed for interoperability testing are transcribed into crates/v2xw-sec/tests/vectors, each with its citation and the source's sha256.
