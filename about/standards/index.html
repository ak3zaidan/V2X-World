Standards and references¶

The standards, specifications and papers the engine's code cites, with the sections it cites most and the modules that implement or calibrate against them. The list is built from the citations in crates/ (doc comments and model cards); a document the code does not cite is not listed. The per-parameter source of every model default is on its card, published on the Model parameters page.

Licensed text

Several of these documents (SAE, IEEE, ETSI before publication, 3GPP drafts) are licensed. The engine reproduces field names, identifiers, constants and table values needed for interoperability, never the text. Test vectors transcribed from licensed documents carry their citation and the source file's hash (tools/oracle/transcribe).
