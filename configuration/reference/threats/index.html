threats¶

Group: Threats. Attackers, jammers and compromised infrastructure.

compromised_rsu_attack¶

Setting Type Unit Default Range or choices Level Status Description
threats.compromised_rsu_attack.id string threat/attacker/compromised-rsu advanced partial The model's registry id. Status: 'threat/attacker/compromised-rsu'. params.kind: PoisonForwardedReports (default: a relayed report is replaced, with poison_prob, by a forgery framing a vehicle the unit heard, and the authority trusts it as infrastructure), SuppressForwardedReports (dropped with suppress_prob) or FalseCrl (fabricated_entries added to each CRL frame; the unit has no CRL Generator key, so every vehicle discards the frame). from_s and to_s bound it. FalseSpat, FalseMap and FalseCtl are refused: nothing acts on SPaT or MAP content yet and units do not broadcast the trust list.
threats.compromised_rsu_attack.params json (serde_json::Value) advanced partial Overrides for its card's defaults. Anything not named here keeps the card's value, which is what makes the parameter set content-addressable. Status: 'threat/attacker/compromised-rsu'. params.kind: PoisonForwardedReports (default: a relayed report is replaced, with poison_prob, by a forgery framing a vehicle the unit heard, and the authority trusts it as infrastructure), SuppressForwardedReports (dropped with suppress_prob) or FalseCrl (fabricated_entries added to each CRL frame; the unit has no CRL Generator key, so every vehicle discards the frame). from_s and to_s bound it. threats.jammers[].id
Value Label Meaning
attacker/jammer/constant Constant A constant wideband jammer: continuous OFDM-like noise in the channel, entering every receiver's noise term for as long as it is on.
attacker/jammer/pulsed Pulsed A duty-cycle jammer: wideband noise for a fraction of a fixed period, with a per-jammer phase drawn from the Attack stream.
attacker/jammer/reactive Reactive A reactive jammer: wideband noise only while energy above a trigger threshold is sensed, which is the profile whose losses are uncorrelated with SINR dips.

Value Label Meaning
threat/attacker/compromised-rsu Compromised roadside unit A trusted unit under an attacker's control poisons or drops what it relays.
