net¶

Group: Network. The network layer between the application and the radio.

28 settings. The status column says whether editing a setting changes a run; see how to read these tables. Paths use [] for a list element and * for a map key.

Status Meaning
wired
partial

General¶

Setting Type Unit Default Range or choices Level Status Description
net.layer string wsmp wsmp, gn-btp advanced wired Which network layer: wsmp or gn-btp.
net.channel_access string continuous, alternating advanced wired IEEE 1609.4 channel access on wsmp: continuous (one channel all the time, the deployed SAE J2945/1 profile; the default) or alternating (50 ms on the control channel, 50 ms on a service channel, a 4 ms guard at each switch: a safety message waits for the next control-channel interval).
net.access_categories string single, etsi-profiles advanced wired Which EDCA queue each message waits in: single (every frame on AC_VO, the deployed SAE J2945/1 profile; the default) or etsi-profiles (the ETSI DCC profiles of TS 102 724: hazard DENMs on AC_VO, CAMs on AC_BE, forwarded GeoNetworking copies and everything else on AC_BK, so a busy channel serves warnings first).
net.dcc_cbr string local, global advanced wired Which channel busy ratio the congestion control acts on (gn-btp only): local (the station's own measurement; the default) or global (the highest of its own, its neighbours' and their neighbours', carried in every GeoNetworking single-hop header, ETSI TS 102 636-4-2), so a station also backs off for congestion it cannot hear itself.

geonet¶

Setting Type Unit Default Range or choices Level Status Description
net.geonet.forwarding string on-air, overlay advanced wired How forwarded copies travel: on-air (each forward is a real frame that queues in the forwarder's MAC, contends, collides, counts in the channel busy ratio and passes the DCC gate; the default) or overlay (a protocol-only run over a disk of range_m at the hazard's instant, with no MAC: optimistic, but instant to compute).
net.geonet.area_forwarding string cbf, simple advanced wired How a warning spreads inside its area: cbf (contention-based: the farthest receiver rebroadcasts first, the rest stand down) or simple (every receiver rebroadcasts once).
net.geonet.non_area_forwarding string greedy, cbf advanced wired How a packet travels towards an area it is not yet in: greedy (to the neighbour nearest the area) or cbf.
net.geonet.cbf_variant string etsi, dpd, gpc advanced wired What a contending vehicle does on hearing a copy: etsi (stand down, and take a later copy as new: many transmissions), dpd (stand down, never forward twice) or gpc (stand down only if the copy came from farther along).
net.geonet.hop_limit integer [1, 255] advanced wired The most hops a warning may take; 10 by default (itsGnDefaultHopLimit).
net.geonet.area_radius_m number m (0, 1784] advanced wired The warning area's radius around the hazard, metres; 1 000 m by default.
net.geonet.range_m number m (0, 3000] advanced wired The single-hop range of the overlay forwarding, metres; 500 m by default. On the air the run's own link budget decides who hears a copy.
net.geonet.repetition_interval_ms integer ms [0, 60000] advanced wired How often the originator repeats the warning, ms; 0 sends it once.
net.geonet.repetition_duration_ms integer ms [0, 600000] advanced wired How long it keeps repeating, ms. Unset, the overlay repeats for 5 000 ms and the on-air DEN service for 15 000 ms (the C2C-CC stationary-vehicle profile); any value given, 5 000 included, is used as given.
net.geonet.keep_alive_forwarding boolean advanced wired Keep-alive forwarding: vehicles in the area re-send a warning they stop hearing, so it reaches vehicles that arrive later.
net.geonet.window_s number s (0, 600] advanced wired How long each warning is followed, seconds.
net.geonet.cbf_min_time_ms integer ms [0, 1000]
recommended 1 ms (EN 302 636-4-1 Annex H).		 advanced wired itsGnGeoBroadcastCbfMinTime, ms: the CBF timer of the farthest contender (EN 302 636-4-1 Annex H, 1 ms unless set). How long the farthest receiver waits before re-broadcasting a geo-broadcast warning.
net.geonet.cbf_max_time_ms integer ms (0, 1000]
recommended 100 ms (Annex H); 20 to 100 ms in studies.		 advanced wired itsGnGeoBroadcastCbfMaxTime, ms: the CBF timer of the nearest contender (Annex H, 100 ms unless set). How long the nearest receiver waits before re-broadcasting; the gap between the two timers decides how cleanly the farthest vehicle wins.
net.geonet.max_comm_range_m number m (0, 5000]
recommended 1,000 m (Annex H); about the real radio range in dense traffic, 300 to 500 m.		 advanced wired itsGnDefaultMaxCommunicationRange (DIST_MAX), m: the progress at which the CBF timer reaches its minimum (Annex H, 1 000 m unless set). The progress at which the contention timer reaches its minimum: the forwarding range the protocol assumes.

rsu_ip¶

Setting Type Unit Default Range or choices Level Status Description
net.rsu_ip.air string constant, sch
recommended constant (default) until the service-channel path is built; sch to study WSA-gated access.		 advanced partial sch (IEEE 1609.3, the default: each relaying unit sends a signed WSA advertising the SCMS service with a WAVE Routing Advertisement, and a vehicle uses a unit only after it has verified that unit's WSA) or constant (the air hop is a fixed latency and rate, and a vehicle uses any relaying unit within range). How a vehicle without a modem reaches the SCMS through a roadside unit: a fixed link, or only after hearing the unit's signed service advertisement (WSA). Air 'constant' (default): a vehicle with no modem uses any relaying unit within 300 m and the hop is a fixed latency and rate. air 'sch' (P19.2): each unit with the provisioning-proxy or report-forward role signs and sends an IEEE 1609.3 WSA every wsa_interval_ms (PSID 0x23, IPv6 Routing, the WAVE Routing Advertisement; v2xw_msg::wsa), and a vehicle binds to a unit only while it holds a verified WSA from it no older than 1 s. A relayed misbehaviour report goes on the radio.channels service channel when the run has one (rule gap M11; a one-radio unit then needs alternating access). Downloads (top-up, re-enrolment, trust fetch) ride TCP/TLS on a service-channel session (transport/80211p-sch: the vehicle's contact window, EDCA AC_BE on the unit's measured CBR, 1609.4 intervals, link-budget loss) and the unit's line; a transfer that fails cuts its flow off, and the vehicle starts it again while a verified unit is in range (relayed_flows_cut_off). Under constant the air hop is the fixed link: the service-channel path (contact window, PER, SCH load) is P19.3-P19.4.*
net.rsu_ip.wsa_interval_ms integer ms [20, 5000]
recommended 100 ms (USDOT RSU Specification v4.1).		 advanced partial The WSA period under sch, ms: 100 (USDOT RSU Specification v4.1 App. D, RepeatRate 50 per 5 s). How often a relaying roadside unit sends its WSA under 'sch'. Applies when net.rsu_ip.air is sch. Air 'constant' (default): a vehicle with no modem uses any relaying unit within 300 m and the hop is a fixed latency and rate. air 'sch' (P19.2): each unit with the provisioning-proxy or report-forward role signs and sends an IEEE 1609.3 WSA every wsa_interval_ms (PSID 0x23, IPv6 Routing, the WAVE Routing Advertisement; v2xw_msg::wsa), and a vehicle binds to a unit only while it holds a verified WSA from it no older than 1 s. A relayed misbehaviour report goes on the radio.channels service channel when the run has one (rule gap M11; a one-radio unit then needs alternating access). Downloads (top-up, re-enrolment, trust fetch) ride TCP/TLS on a service-channel session (transport/80211p-sch: the vehicle's contact window, EDCA AC_BE on the unit's measured CBR, 1609.4 intervals, link-budget loss) and the unit's line; a transfer that fails cuts its flow off, and the vehicle starts it again while a verified unit is in range (relayed_flows_cut_off). Choices¶

The labelled values of every closed or model setting above.

net.layer
Value Label Meaning
wsmp WSMP (IEEE 1609.3, US) The US short message protocol: a 5-octet header on a BSM.
gn-btp GeoNetworking + BTP (ETSI, Europe) The European network and transport layers: 44 octets of headers on a CAM.
net.channel_access
Value Label Meaning
continuous Continuous (one channel) The deployed US profile: safety messages go out on one channel as soon as they are made.
alternating Alternating (IEEE 1609.4) One radio switches channel every 50 ms; a message made on the wrong half waits up to 54 ms, and one that would run into the 4 ms switch guard waits too.
net.access_categories
Value Label Meaning
single One queue (AC_VO) Every message waits in the same top-priority queue, as deployed US radios do.
etsi-profiles ETSI DCC profiles Hazard warnings jump the queue; CAMs and forwarded copies wait longer when the channel is busy.
net.dcc_cbr
Value Label Meaning
local Own measurement Each radio throttles for the channel load it hears itself.
global Two-hop maximum (ETSI GeoNetworking) Radios share their load in every header and throttle for congestion up to two hops away.
net.fragmenter.id
Value Label Meaning
fragmenter/cert-cycle-partial-hybrid Post-quantum certificate spread over a cycle The hybrid certificate rides in the first messages of each five-message cycle.
fragmenter/facilities-segmentation Independent segments (ETSI) Each segment is a message of its own (GeoNetworking only).
fragmenter/generic-sdu Split into pieces A large message is sent in pieces and reassembled; it arrives only if every piece does.
fragmenter/none No fragmentation A signed message larger than the network's limit is refused.
net.backhaul.id
Value Label Meaning
backhaul/fixed Fixed line A wired link with a set latency and capacity.
backhaul/fibre Fibre Metro fibre to the backend: 1 Gbit/s and well under a millisecond.
backhaul/dsl DSL (copper) A VDSL2 phone line: 20 Mbit/s up, 80 down, about 9 ms each way.
backhaul/microwave Microwave A point-to-point radio hop: 400 Mbit/s, about 0.2 ms, rare outages.
backhaul/cellular Cellular The unit reaches the backend over the mobile network.
backhaul/none None (offline) The unit has no backend link.
net.uu.id
Value Label Meaning
cellular/uu/cell-capacity-mm1 Cellular with cell capacity Each cell's capacity shared by its users (an M/M/1 queue per device).
cellular/uu/fixed-latency Cellular, measured latency A fixed one-way latency measured on a real network.
cellular/uu/handover-outage Cellular with handovers Adds the interruption and loss of handovers between cells.
cellular/uu/packet-pf Cellular, packet level Real base stations, a shared scheduler, retransmissions and TCP/TLS for backend traffic; slower to run.
net.backend_net.id
Value Label Meaning
backend-net/fixed Fixed links Links between backend authorities with a set latency and capacity.
net.geonet.forwarding
Value Label Meaning
on-air On the air (recommended) Each forwarded copy is a real frame: it queues, contends, can collide and loads the channel.
overlay Protocol only (no MAC) Forwarding runs over a fixed radio range with no contention or collisions: optimistic reach.
net.geonet.area_forwarding
Value Label Meaning
cbf Contention-based (CBF) The farthest receiver rebroadcasts first and the nearer ones stand down: few transmissions, the standard's choice.
simple Flooding (simple) Every vehicle rebroadcasts the warning once: fast and robust, many transmissions.
net.geonet.non_area_forwarding
Value Label Meaning
greedy Greedy Hand the warning to the neighbour nearest the area (the standard's default).
cbf Contention-based Broadcast towards the area; the receiver that gets closest rebroadcasts first.
net.geonet.cbf_variant
Value Label Meaning
etsi As evaluated in Artery (no duplicate check) A copy heard after forwarding is taken as new: very many transmissions (Amador et al. 2022).
dpd With duplicate detection Each vehicle forwards a warning at most once; any copy makes a contender stand down, which can stall the spread.
gpc Geographic cancellation (recommended) Stand down only when the copy came from farther along: near-full reach at low overhead (Amador et al. 2022).
net.rsu_ip.air
Value Label Meaning
constant Constant air link The hop to a relaying roadside unit is a fixed delay and rate, and any unit in range serves.
sch Advertised service (IEEE 1609.3) Each relaying unit sends a signed WSA for the SCMS service; a vehicle uses a unit only after it verified that unit's WSA.
