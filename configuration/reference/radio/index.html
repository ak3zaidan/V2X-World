radio¶

Group: Radio. The radio stack: which technology, at which fidelity, with which models.

98 settings. The status column says whether editing a setting changes a run; see how to read these tables. Paths use [] for a list element and * for a map key.

Status Meaning
wired
partial

General¶

Setting Type Unit Default Range or choices Level Status Description
radio.rat string dsrc-80211p dsrc-80211p, lte-v2x-pc5, nr-v2x-pc5, hybrid
recommended DSRC or LTE-V2X: the two deployed today.		 basic wired Which radio access technology. Which V2X radio vehicles use: DSRC (IEEE 802.11p, the original Wi-Fi-based standard), LTE-V2X (4G sidelink, 3GPP Release 14) or NR-V2X (5G sidelink, Release 16).
radio.region string us, us-2016, eu advanced wired The regulatory region: its band plan, the channel each technology deploys on and the EIRP limits (v2xw_radio::regulation). Unset, the region the technology was deployed under: us-2016 for 802.11p (the DSRC band plan SAE J2945/1 was written for), us for LTE-V2X and NR-V2X (FCC 24-123).
radio.channel integer channel number [170, 184]
172, 174, 176, 178, 180, 181, 182, 183, 184		 advanced wired The channel number within the region's band plan. Unset, the region's deployment channel for the technology.
radio.channel_leakage boolean advanced wired Whether the run's own channels leak into each other through the transmitter mask and the receiver's selectivity (the ACIR of v2xw_radio::regulation). Unset is on; false is ideal channel filters. Only acts with radio.channels.

phy¶

Setting Type Unit Default Range or choices Level Status Description
radio.phy.data_rate_mbps number Mbit/s [3, 27]
recommended 6 Mbit/s (the US default); 3 for range, 12 to 18 for crowded channels.		 basic wired The data rate every safety frame is sent at, Mbit/s: one of 3, 4.5, 6, 9, 12, 18, 24 or 27 (the eight 10 MHz OFDM rates of IEEE 802.11-2020 Table 17-4). A higher rate takes less air time per frame but needs a stronger signal, so it trades range for channel capacity. Unset is 6 Mbit/s, the SAE J2945/1 default. The 802.11p data rate (modulation and coding). Faster rates finish each frame sooner, so more radios fit on the channel, but they need a stronger signal, so range shrinks.
radio.phy.noise_figure_db number dB [0, 15]
recommended 6 dB (automotive module) to 9 dB (3GPP UE).		 advanced wired The receiver noise figure, dB: how much noise the receiver's own electronics add on top of the thermal floor of −104 dBm in 10 MHz. Unset is the hardware figure the PHY card cites (6 dB). How much noise the receiver's own electronics add; every extra dB costs about 10 % of range in free space.
radio.phy.sensitivity_dbm number dBm [-105, -60]
recommended -92 dBm (fielded units) to -85 dBm (ETSI minimum).		 advanced wired One receiver sensitivity at every data rate, dBm: a frame weaker than this is not decoded (Veins' minPowerLevel). Unset uses the per-rate table that radio.models.phy selects (fielded units, −92 dBm at 6 Mbit/s). The weakest frame the receiver decodes, at every data rate (Veins' minPowerLevel).
radio.phy.cca_threshold_dbm number dBm [-100, -50]
recommended -85 dBm (ETSI); -82 (ns-3); -65 (Veins).		 advanced wired The carrier-sense (CCA) threshold, dBm: energy above it makes a radio treat the channel as busy, defer its transmission and count the time in the channel busy ratio. Unset is −85 dBm (ETSI EN 302 571 §4.2.10.1). The signal level at which a radio hears the channel as busy and holds back; it also sets what the channel busy ratio counts.
radio.phy.energy_detect_dbm number dBm [-100, -50]
recommended -65 dBm (IEEE 802.11-2020 §17.3.10.6, 10 MHz); -62 (ns-3); -85 reproduces the older single-threshold carrier sense.		 advanced wired The energy-detect level, dBm: another channel's frame leaking through the channel filter holds carrier sense busy only above it (and, under SAE J2945/1, counts in the CBP only above it). Unset is −65 dBm, 20 dB above the 10 MHz minimum sensitivity (IEEE 802.11-2020 §17.3.10.6); never below cca_threshold_dbm. −85 dBm is the carrier sense before radio-fix4, which held a leak to the preamble level. The level at which another channel's frame, leaking through the filter, makes the radio hear its own channel as busy.
radio.phy.capture_threshold_db number dB [0, 30]
recommended Unset (error model); 4 to 10 dB to compare with threshold-based simulators.		 advanced wired A hard capture threshold, dB: a frame is decoded only while it stays this far above the interference plus noise (Torrent-Moreno 2009, Eq. 1). Unset uses the SINR trace against the error model, as Veins does. Replaces the error model with a hard rule: a frame survives only if it stays this many dB above interference plus noise.

mac¶

Setting Type Unit Default Range or choices Level Status Description
radio.mac.edca_profile string by-region by-region, sae-j2945-1, en-302-663
recommended By region (the default); SAE J2945/1 or EN 302 663 to compare the two on one map.		 advanced wired Which EDCA table the MAC contends with, and so where a BSM waits (EdcaProfileSpec). Unset is by-region: SAE J2945/1 Table 18 for 802.11p under a US region, ETSI EN 302 663 elsewhere (wiring::edca_profile). An explicit cw_min_* or aifsn_* below still wins over the table's own value. Which table of waiting times the radio uses before it sends: the US safety-message standard's, where a routine safety message waits a little longer than an emergency one, or the European default.
radio.mac.periodic_access_category string vo, vi, be, bk
recommended Video for a US BSM (SAE J2945/1 user priority 5) or a European CAM; voice is a critical BSM's.		 advanced wired The access category periodic awareness messages (BSM, CAM, PSM, VAM, CPM, SPaT, MAP) are queued in: vo, vi, be or bk. Unset is vo, the highest, except for a BSM under SAE J2945/1 Table 18 (below). SAE J2945/1 §6.3.4 puts a BSM without a critical event flag at user priority 5, which is AC_VI (UPEDCA-001), and one with a flag at user priority 7, AC_VO (UPEDCA-002); EN 302 663 Annex C puts the CAM at vi. Unset under SAE J2945/1 Table 18 (MacSettings::edca_profile), a BSM is queued by its flags in exactly that way (wiring::bsm_queue_by_flags); set, it names the queue of every periodic message, the BSM included. The priority queue awareness messages wait in; higher priorities wait less before sending.
radio.mac.event_access_category string vo, vi, be, bk
recommended Voice.		 advanced wired The access category event messages (DENM, forwarded hazard warnings) are queued in. Unset is vo (EN 302 663 Annex C). The priority queue hazard warnings (DENM) wait in.
radio.mac.cw_min_vo integer slots [1, 1023]
recommended 3 (standard) to 15 in dense traffic.		 advanced wired CWmin of the voice category, slots: a frame waits a random 0 to CWmin idle slots before it may start. A larger window means fewer collisions and more delay. Unset is 3 (EN 302 663 Table C.4). Broadcast never doubles it, so there is no CWmax to set. The random back-off window of the voice queue: a wider window spreads transmissions out, which means fewer collisions and more delay.
radio.mac.aifsn_vo integer slots [2, 15]
recommended 2 (standard).		 advanced wired AIFSN of the voice category, slots: the fixed idle wait before the countdown. Unset is 2. The fixed idle wait of the voice queue before its back-off countdown.
radio.mac.cw_min_vi integer slots [1, 1023]
recommended 15 under a US region (SAE J2945/1 Table 18), 7 elsewhere (EN 302 663).		 advanced wired CWmin of the video category, slots. Unset is 15 for 802.11p under a US region (SAE J2945/1 Table 18) and 7 elsewhere (EN 302 663). The random back-off window of the video queue.
radio.mac.aifsn_vi integer slots [2, 15]
recommended 4 under a US region (SAE J2945/1 Table 18), 3 elsewhere (EN 302 663).		 advanced wired AIFSN of the video category, slots. Unset is 4 for 802.11p under a US region (SAE J2945/1 Table 18) and 3 elsewhere (EN 302 663). The fixed idle wait of the video queue.
radio.mac.queue_length integer frames [1, 1024]
recommended 16 to 64.		 advanced wired How many frames each access category queues before it drops the next. Unset is 64. How many frames wait in each priority queue before new ones are dropped.

channel_model¶

Setting Type Unit Default Range or choices Level Status Description
radio.channel_model.path_loss_exponent number [1.5, 6]
recommended 1.8 (highway) to 3.5 (dense city).		 advanced wired A single-slope path-loss exponent: 2 is free space, about 2.7 to 3.5 a city street. Setting it, or the shadowing spread, runs the log-distance law (propagation/log-distance-shadowing) with these numbers over a free-space anchor at 10 m. Unset keeps the measured dual-slope fits. How fast the signal weakens with distance: 2 in free space, near 3 in a built-up street. Setting it runs the log-distance law.
radio.channel_model.shadowing_sigma_db number dB [0, 15]
recommended 3 to 4 dB in line of sight, 6 to 7 dB obstructed.		 advanced wired The log-normal shadowing standard deviation, dB: how much the received power wanders around the path-loss mean as buildings and trucks come and go. Unset keeps the fit's own (about 4 dB in line of sight, 6 to 7 dB obstructed, Abbas 2015). How much the signal wanders around its average as buildings and trucks block it.
radio.channel_model.shadowing_decorrelation_m number m (0, 500]
recommended 10 m (city) to 50 m (highway).		 advanced wired How far a vehicle moves before its shadowing is uncorrelated with what it was, metres (Gudmundson 1991). Unset is the environment's (about 10 m in a city). How far a vehicle travels before its shadowing changes completely.
radio.channel_model.fading string none, rayleigh, rice, nakagami
recommended Leave unset (Nakagami m = 3); Rayleigh for a worst case.		 basic wired The small-scale fading law: none, rayleigh (no direct path), rice (a direct path rice_k_db stronger than the scatter) or nakagami (shape nakagami_shape). Unset keeps the tier's choice (Nakagami m = 3 for 802.11p). The fast signal fluctuation as vehicles move a few centimetres: Rayleigh has no direct path, Rice and Nakagami have one. It is the main cause of losses well inside range.
radio.channel_model.fading_coherence string independent, doppler
recommended independent (today's behaviour); doppler for burst-loss studies (Akki & Haber 1986; Rappaport 2002 Eq. 5.40c).		 advanced wired How the fade of one link changes from frame to frame: independent (each frame draws its own, the default) or doppler (one fade per coherence time, 0.423 / f_D with f_D from both ends' speeds and the carrier, so slow links fade in bursts and fast links decorrelate; Akki & Haber 1986, Rappaport 2002 Eq. 5.40c). Whether a link's fade carries over from one message to the next: with doppler, vehicles standing still (a queue at a red light) keep a bad fade for many messages in a row, while fast vehicles get a fresh fade with every message.
radio.channel_model.nakagami_shape number [0.5, 20]
recommended 1 to 5.		 advanced wired The Nakagami shape m when fading is nakagami (written m in the literature): 1 is Rayleigh, larger is milder. Unset is 3. The Nakagami shape m: 1 is Rayleigh, larger values are milder fading.
radio.channel_model.rice_k_db number dB [-10, 30]
recommended 3 to 10 dB.		 advanced wired The Rice factor K when fading is rice, dB: the direct path's power over the scattered power's. Unset is 6 dB. The strength of the direct path over the scattered ones in a Rice channel.
radio.channel_model.nakagami_shape_far number [0.5, 20]
recommended 0.75 to 1 beyond about 80-100 m.		 advanced wired The Nakagami m beyond nakagami_breakpoint_m, when fading is nakagami, for a channel that gets harsher with range (Veins-style: about 1.5 near, 0.75 far). Needs the breakpoint. Unset keeps nakagami_shape at every distance. The fading severity beyond the breakpoint distance, for a channel that gets harsher with range.
radio.channel_model.nakagami_breakpoint_m number m (0, 5000]
recommended 80 to 100 m.		 advanced wired The distance at which the Nakagami m switches to nakagami_shape_far, metres. The distance at which the fading switches to its far-away severity.
radio.channel_model.building_wall_loss_db number dB [0, 40]
recommended 9 dB (Sommer 2011 default); 2.4 dB for light construction.		 advanced wired How much each building wall the signal passes through costs (Sommer 2011 β), dB: 9 dB for the fitted default, about 2.4 dB for light construction. How much each building wall between two cars costs the signal (Sommer 2011's β, as Veins models it).
radio.channel_model.building_loss_db_per_m number dB/m [0, 10]
recommended 0.4 dB/m (Sommer 2011 default); 0.1-0.63 dB/m across the fitted rows.		 advanced wired How much each metre of path inside a building costs (Sommer 2011 γ), dB per metre: 0.4 for the fitted default. How much each metre of the path inside a building costs (Sommer 2011's γ).
radio.channel_model.vehicle_blockage boolean recommended On for realism; off to measure what blockage costs. advanced wired Whether other vehicles between two antennas attenuate the signal (3GPP TR 37.885 NLOSv blockage). On by default with the city-street law; off makes vehicles radio-transparent, on charges them under every law. Whether trucks and cars between two antennas weaken the signal (3GPP TR 37.885 NLOSv).
radio.channel_model.foliage boolean recommended Off (today); on with world.vegetation for suburban and rural maps with woods and tree-lined streets. advanced wired Whether a path through trees loses the foliage excess (ITU-R P.833 §3.1 with GEMV²'s 2.3 dB/m at 5.9 GHz, capped at the diffraction over the canopy: obstacle/foliage/p833). Needs world.vegetation. Unset is off. Whether trees between two antennas weaken the signal: about 2.3 dB per metre of trees at 5.9 GHz, up to what bending over the treetops would cost. Needs world.vegetation.
radio.channel_model.density_sigma boolean recommended Off (today, a fixed spread); on for the measured dependence on surroundings. advanced wired Whether the log-distance law's shadowing σ grows with the vehicles and buildings around the link (GEMV², Boban et al. 2014 eq. 10: 3.3 dB on an empty road to 5.2 dB downtown for line of sight). Unset keeps the preset's fixed σ. Whether the signal's random variation grows with the traffic and buildings around each link, as measured in Porto (GEMV2): calmer on an empty road, rougher downtown.
radio.channel_model.reflection boolean recommended Off (today); on for downtown maps, where reflections carry links round corners. advanced wired Whether a building-blocked link also receives the strongest single specular reflection off a building wall, power-summed with the shadowed path (GEMV², Boban et al. 2014 §IV-B.3, eqs. 6-8; ITU-R P.2040-3 Table 3 for the walls: obstacle/reflection/gemv2-single-bounce). Needs buildings. Unset is off. Whether a signal blocked by a building can still arrive by bouncing once off another building's wall, as it does down a street canyon: the bounce costs its longer path and the wall's reflection loss.

dcc¶

Setting Type Unit Default Range or choices Level Status Description
radio.dcc.enabled boolean recommended On, except as the baseline of a congestion study. basic wired Whether 802.11p congestion control runs at all. false lets every radio send at its full rate and power however busy the channel is: the baseline a DCC study compares against. Unset is on (EN 302 571 requires it in Europe). Congestion control: radios slow down or turn their power down when the channel is busy, so the channel stays usable. Turn it off to measure what it buys.
radio.dcc.cbr_target number [0.1, 0.95]
recommended 0.6 to 0.7 (standard 0.68).		 advanced wired The channel load the ETSI adaptive algorithm steers towards, as a fraction of time busy. Unset is 0.68 (TS 102 687 V1.2.1 Table 3). The share of time busy the ETSI adaptive algorithm aims the channel at.
radio.dcc.adaptive_alpha number [0.001, 0.5]
recommended 0.016 (standard).		 advanced wired The ETSI adaptive smoothing factor α: how much of each new load measurement enters the running average. Unset is 0.016 (ibid.). How quickly the ETSI adaptive algorithm's load average follows new measurements.
radio.dcc.adaptive_beta number [0.0001, 0.05]
recommended 0.0012 (standard).		 advanced wired The ETSI adaptive gain β: how hard the allowed duty cycle reacts to the gap from the target. Unset is 0.0012 (ibid.). How strongly the ETSI adaptive algorithm changes the allowed airtime when the load is off target.
radio.dcc.max_itt_ms number ms [100, 2000]
recommended 600 ms (standard).		 advanced wired The longest interval SAE J2945/1 may stretch a BSM's spacing to under congestion, ms (vMax_ITT). Unset is 600 ms. The longest gap J2945/1 allows between one vehicle's BSMs under congestion.
radio.dcc.density_coefficient number vehicles [1, 200]
recommended 25 (standard).		 advanced wired The vehicle density at which SAE J2945/1 starts to stretch the interval (B, vehicles within 100 m). Unset is 25. How many neighbours within 100 m J2945/1 tolerates before it stretches the BSM interval.
radio.dcc.power_control boolean recommended On (J2945/1); off for rate-only control. advanced wired Whether SAE J2945/1 also lowers the radiated power as the channel fills. radio.dcc.min_power_dbm number dBm [-10, 20]
recommended 10 dBm (standard).		 advanced wired The lowest power J2945/1's power control may go to, dBm (vRP_Min). Unset is 10. The lowest power J2945/1's power control may reach.
radio.dcc.reactive_table string a1, a2
recommended A.1 for secured CAMs at 6 Mbit/s; A.2 only for short frames.		 advanced wired ETSI reactive DCC's table (TS 102 687 V1.2.1 Annex A): a1 (frames up to 1 ms on air, Table A.1, the default) or a2 (up to 500 µs, Table A.2, twice the rates). Which ETSI reactive table sets the message rate in each congestion state: A.1 for frames up to 1 ms on air, A.2 (twice the rates) for frames up to 500 µs.
radio.dcc.reactive_hold_ms number ms [0, 5000]

How long reactive congestion control stays in a state before it may step again; longer holds damp oscillation.
radio.dcc.channel_quality string sae-j2945-1, fmvss150-nprm
recommended SAE J2945/1 Eq. 4 (the default); the FMVSS 150 NPRM smoothing only to reproduce older results.		 advanced wired SAE J2945/1's channel-quality indicator Π: sae-j2945-1 (unset) is 6.3.8.1 Eq. 4, the mean PER of the neighbours within 100 m capped at 0.3; fmvss150-nprm smooths it with weight 0.9 on the previous value, as the withdrawn FMVSS 150 NPRM transcribed it (11-j2945-1-conformance.md J3a). sidelink¶

Setting Type Unit Default Range or choices Level Status Description
radio.sidelink.reservation_interval_ms integer ms [1, 1000]
recommended 100 ms for 10 Hz BSMs; 20 or 50 ms for faster traffic.		 advanced wired How often a radio's reserved resource repeats, ms (the resource reservation interval, RRI). LTE allows 20, 50, 100 or a multiple of 100 up to 1,000 (TS 36.331 sl-ResourceReservationPeriod); NR also 1 to 99. Unset is 100 ms, one BSM period. How often a C-V2X radio's booked slot repeats; it should match how often the radio has a message to send.
radio.sidelink.resource_keep_probability number [0, 0.8]
recommended 0.8 (J3161/1); 0 to study fast reselection.		 advanced wired The probability a radio keeps its resource when the reselection counter runs out (probResourceKeep): 0, 0.2, 0.4, 0.6 or 0.8 (TS 36.331). Higher keeps reservations stable for others to sense, but makes two radios that collide keep colliding. Unset is the profile's (0.8 under SAE J3161/1). The chance a radio keeps its booked slot when its counter runs out, rather than picking a new one.
radio.sidelink.rsrp_threshold_dbm number dBm [-128, -60]
recommended -128 dBm (NR studies) to -110 dBm (LTE studies).		 advanced wired The RSRP above which a resource another radio reserved is excluded from selection, dBm; it is raised 3 dB at a time until enough candidates remain (TS 36.213 §14.1.1.6). Unset is the profile's (−128 dBm NR, −110 dBm LTE studies). How strong another radio's booking must be for a radio to avoid that slot.
radio.sidelink.sensing boolean recommended On; off only as a baseline. advanced wired Whether radios sense the channel before choosing a resource. false is the random selection baseline (Ali et al. 2021 §II.1). Unset is on. Whether radios listen before booking a slot. Off is the random-selection baseline.
radio.sidelink.candidate_percent integer % [20, 50]
recommended 20 % (LTE's fixed value); 35 or 50 % on NR.		 advanced wired The share of the selection window that must survive exclusion before a radio picks: 20 % (LTE's fixed value), 35 % or 50 % (NR only). Unset is 20 %. The share of resources that must remain after exclusion before a radio picks one.
radio.sidelink.selection_window_ms integer ms [1, 100]
recommended 100 ms at 10 Hz; at most the message interval.		 advanced wired How late after a message is ready its new resource may be (the selection window's end T2), ms. Shorter cuts latency but leaves fewer resources to pick from; at most the message interval. Unset is the profile's (100 ms at 10 Hz). How late after a message is ready its new resource may be. Shorter cuts latency but leaves fewer resources to pick from.
radio.sidelink.noise_figure_db number dB [0, 15]
recommended 9 dB (3GPP TR 36.885 UE); 6 dB for a good automotive module.		 advanced wired The UE receiver noise figure, dB: TR 36.885 Annex A.1.1's 9 dB unless set. It moves every sidelink noise floor (and the candidate range measured against it). How much noise a C-V2X receiver's own electronics add; every extra dB shortens the range at which a transport block still decodes.
radio.sidelink.cbr_threshold_dbm number dBm [-112, -8]
recommended -94 dBm (this build's default); -112 to -80 dBm in 2 dB steps (TS 36.331).		 advanced wired sl-ThresS-RSSI-CBR, dBm: the S-RSSI above which a sub-channel counts as busy in the channel busy ratio (TS 36.214 §5.1.30, TS 36.331 range -112 to -8 dBm in 2 dB steps). -94 dBm unless set; the CR limits and every CBR metric read it. The signal level above which a C-V2X sub-channel counts as busy in the channel busy ratio, which drives congestion control.
radio.sidelink.align_generation boolean recommended Off (today's default, every LTE-V2X run unchanged); on for a deployment-faithful LTE-V2X latency. advanced wired Whether each radio generates its periodic BSM just before its reserved resource, as SAE J3161/1 has the application do, instead of on its own 100 ms clock: the BSM then waits a margin for its resource rather than up to a whole period. The phase follows every reselection; an interval it changes stays inside J2945/1's bounds. Unset is off. Whether each C-V2X radio builds its safety message just before its reserved slot, as SAE J3161/1 has deployed radios do, so the message waits a millisecond or two for the air instead of up to a tenth of a second.
radio.sidelink.align_margin_ms number ms [0, 50]
recommended 1 ms (the radio's processing time T1); an assumption until J3161/1's own figure is read.		 advanced wired How long before its reserved resource an aligned BSM reaches the radio, ms, on top of the device's longest signing time. Unset is the pool's processing time T1 (1 ms on LTE-V2X): an ASSUMPTION until J3161/1's figure is read. With aligned generation, how long before its reserved slot the signed message reaches the radio, on top of the longest time the device takes to sign it.
