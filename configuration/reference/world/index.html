world¶

Group: World. The map: where it comes from, its buildings and its terrain.

26 settings. The status column says whether editing a setting changes a run; see how to read these tables. Paths use [] for a list element and * for a map key.

Status Meaning
wired

General¶

Setting Type Unit Default Range or choices Level Status Description
world.imported_at string "" advanced wired The import date, ISO-8601 UTC, supplied here rather than read from a clock. It reaches v2xw_world::ImportOptions::imported_at unchanged and is excluded from the world's content hash.
world.cache string advanced wired Where an imported world is cached, so a repeated run skips the import.
world.highway_preset string sumo-german, urban-us-nyc, urban-us-portland, urban-de, urban-us-ak, urban-us-al, urban-us-ar, urban-us-az, urban-us-ca, urban-us-co, urban-us-ct, urban-us-dc, urban-us-de, urban-us-fl, urban-us-ga, urban-us-hi, urban-us-ia, urban-us-id, urban-us-il, urban-us-in, urban-us-ks, urban-us-ky, urban-us-la, urban-us-ma, urban-us-md, urban-us-me, urban-us-mi, urban-us-mn, urban-us-mo, urban-us-ms, urban-us-mt, urban-us-nc, urban-us-nd, urban-us-ne, urban-us-nh, urban-us-nj, urban-us-nm, urban-us-nv, urban-us-oh, urban-us-ok, urban-us-pa, urban-us-ri, urban-us-sc, urban-us-sd, urban-us-tn, urban-us-tx, urban-us-ut, urban-us-va, urban-us-vt, urban-us-wa, urban-us-wi, urban-us-wv, urban-us-wy, urban-us-boston advanced wired Which named set of highway=* class defaults the OSM importer falls back on.
world.service_roads boolean advanced wired Service roads
world.vegetation boolean recommended Off (today); on with radio.channel_model.foliage where trees line the roads. advanced wired Whether the OSM importer keeps the trees as a vegetation layer ( : woods and forests, tree rows, single trees; v2xw_world::osm::OsmOptions::vegetation), which radio.channel_model.foliage charges. Default false, and a world imported without it keeps its content hash. Whether the map import keeps woods, tree rows and single trees, so the radio can charge for signal through foliage.

source¶

Setting Type Unit Default Range or choices Level Status Description
world.source.generator string world/source/procedural-grid world/source/procedural-grid, world/source/procedural-radial, world/source/procedural-random (or another value) advanced wired The generator's model id, e.g. world/source/procedural-grid. Model slot: family world, see model parameters.
world.source.params json (serde_json::Value) null advanced wired Its parameters, in the shape that generator's parameter struct deserialises.
world.source.path string advanced wired Path to the .osm or .osm.xml file. Or, for another variant: Path to the network file. Or, for another variant: Path to the .xodr file. Or, for another variant: Path to the file.
world.source.bbox.min_lat_deg number ° advanced wired South edge, degrees north.
world.source.bbox.min_lon_deg number ° advanced wired West edge, degrees east.
world.source.bbox.max_lat_deg number ° advanced wired North edge, degrees north.
world.source.bbox.max_lon_deg number ° advanced wired East edge, degrees east.
world.source.params.ew_green_share number 0.5 [0.1, 0.9]
recommended 0.5 for equal demand (Webster 1958); 0.3 to 0.7, in proportion to the two streets' flows.		 advanced wired On a generated grid with traffic lights, the share of each light's green time the east-west street gets; the north-south street gets the rest. Give more to the busier street.

buildings¶

Setting Type Unit Default Range or choices Level Status Description
world.buildings.enabled boolean true advanced wired Import building footprints at all.
world.buildings.keep_holes boolean true advanced wired Keep interior holes in footprints.
world.buildings.metres_per_level number m/storey [1.5, 10] advanced wired Metres per storey for the building:levels rule. TODO: calibrate upstream (v2xw_world::ImportOptions::metres_per_level); a scenario that has a local fit sets it here.

terrain¶

Setting Type Unit Default Range or choices Level Status Description
world.terrain.dem string advanced wired Path to a DEM raster, when the scenario has one.
world.terrain.drape boolean recommended Off for flat maps; on with a terrain file wherever grades matter (hills slow heavy trucks). advanced wired Lay the world on the DEM: every lane centreline point, junction, crossing end, building, site and signal head is lifted by the DEM's height at its position (v2xw_world::DrapeOptions::all, "lane z is taken from the DEM where the source network has no z"), so a lane has the slope traffic.vehicle_dynamics.grade reads. Off by default: the DEM is then only the ground the radio's knife-edge diffraction reads, and the geometry stays flat. Needs dem. Whether the roads, junctions and buildings follow the ground of the terrain file, so a road over a hill climbs and descends with it.

signals¶

Setting Type Unit Default Range or choices Level Status Description
world.signals.coordinate boolean advanced wired Offset the plans along each major road for a green wave.
world.signals.progression_speed_mps number m/s [1, 40] advanced wired The green wave's speed, m/s; absent, each link's speed limit.
world.signals.cycle_s number s [30, 180]
recommended 60 to 120 s; 90 s is the default.		 basic wired The cycle length of the synthesised signal plans, seconds. Unset is 90 s (netconvert --tls.cycle.time). Imported (OSM) worlds only. How long a traffic light takes to go through all its phases and come back to green on an imported city map.
world.signals.all_red_s number s [0, 6]
recommended 0 to 2 s; the ITE formula may add more.		 advanced wired The shortest all-red between phases, seconds; the ITE red-clearance formula may give more. Unset is 0 (netconvert --tls.allred.time). Imported worlds only. The shortest time all directions see red between phases, so the junction clears.
world.signals.pedestrian_walk_s number s [4, 30]
recommended 7 s (MUTCD minimum); 4 to 10 s.		 advanced wired The pedestrian walk interval each phase's green must leave room for, seconds. Unset is 7 s (MUTCD 2009 §4E.06 minimum). Imported worlds only. How long the walk signal shows; each green is made long enough for it and the crossing.
world.signals.pedestrian_speed_mps number m/s [0.8, 1.5]
recommended 1.067 m/s (MUTCD 3.5 ft/s); 0.91 m/s near schools or seniors.		 advanced wired The walking speed pedestrian clearance is timed for, m/s. Unset is 1.067 m/s (3.5 ft/s, MUTCD 2009 §4E.06). Imported worlds only. The walking speed the flashing don't-walk time is timed for: slower gives pedestrians longer and drivers shorter greens.
world.signals.join_m number m [0, 40]
recommended Off (0) as imported; 20 m (SUMO's netconvert default); 10 to 30 m.		 advanced wired Joins two signalised junctions whose connecting road is at most this long, metres, into one junction with one signal plan (netconvert --tls.join, whose --tls.join-dist default is 20 m). Unset joins none. Imported worlds only. Two traffic lights this close together on an imported map run as one junction with one plan, so cars are never fed into the short gap between them faster than it empties.

sumo¶

Setting Type Unit Default Range or choices Level Status Description
world.sumo.signal_programmes json (v2xw_world::sumo::ProgrammeImport) as-file, static
recommended As the file says: flattening an actuated programme to fixed time changes every queue and green it serves.		 advanced wired as-file (the default): an actuated, delay-based or NEMA &lt;tlLogic&gt; runs as the live controller its type names, with its phases' minDur/maxDur and its &lt;param&gt;s (v2xw_world::sumo::ProgrammeImport). Whether a SUMO network's actuated and NEMA traffic lights run as the live controllers the file names, or as their fixed phase lists.

world.source.generator
Value Label Meaning
world/source/procedural-grid Procedural grid A rectangular lattice of two-way streets with signalised or priority junctions, generated deterministically from its parameters: the reference world for tests, calibration runs and the TR 36.885 ur…
world/source/procedural-radial Procedural radial The classic radial city: spokes from a central plaza crossed by concentric ring roads, generated deterministically from its parameters.
world/source/procedural-random Procedural random An irregular road network grown from one junction by random attachment: oblique approaches, three-arm junctions, cul-de-sacs and uneven blocks, reproducible from its seed.
