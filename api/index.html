Rust API¶

The rustdoc of every workspace crate is built by CI (cargo doc --workspace --no-deps) and served under this section of the site. Every library crate except v2xw-demand, v2xw-interop and v2xw-netval denies missing docs, so every public item is documented. Each crate's front page opens with a module table naming where each concern lives. Crate roles and dependency order: Crates.

If a crate link below does not open

The rustdoc pages are published by the site's automatic deployment. Until a deployment has included them, build them locally with the commands below; they are the same pages.

Build locally¶

cargo doc --workspace --no-deps --open      # all crates, opens target/doc in a browser
cargo doc -p v2xw-engine --no-deps --open   # one crate
