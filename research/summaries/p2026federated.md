# Federated Deep Learning for Intrusion Detection in Vehicle-to-Vehicle Networks: A Comprehensive Survey
Ranjima P, Devi Kannan · 2026 5th International Conference on Communication, Computing and Electronics Systems (ICCCES) 2026 · https://doi.org/10.1109/iccces62661.2026.11436374 · relevance: medium · basis: abstract

**Problem:** Vehicle-to-Vehicle (V2V) communication functions as a core technology for Intelligent Transportation Systems (ITS) because it allows vehicles to exchange safety data in real-time for enhanced traffic control and improved road safety.
**Approach:** The paper introduces a systematic classification system which organizes security threats and IDS architectures and federated aggregation techniques and performs an evaluation of available datasets and tools and robustness approaches.
**Tools and scale:** The open nature of V2V networks together with their ability to move freely creates significant security risks because they can be easily targeted by cyber-attacks which include spoofing and denial-of-service and new adversarial machine learning threats.
**Results:** Vehicle-to-Vehicle (V2V) communication functions as a core technology for Intelligent Transportation Systems (ITS) because it allows vehicles to exchange safety data in real-time for enhanced traffic control and improved road safety.
