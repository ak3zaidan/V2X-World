# Adapting Foundation Models for Operator Data Analytics
Manikanta Kotaru · Proceedings of the 22nd ACM Workshop on Hot Topics in Networks 2023 · https://doi.org/10.1145/3626111.3628191 · relevance: medium · basis: abstract

**Problem:** The complexity of operator networks and myriad of specialized metrics produced by network function providers present a formidable challenge in retrieving and analyzing operator data, a vital component for network operations. This necessitates specialist intervention, which is time-consuming and limits customization.
**Approach:** This paper proposes Data Intelligence for Operators Copilot, a natural language interface for retrieval and analytics tasks on operator data, leveraging foundation models.

**Results:** The system has outperformed state-of-the-art natural language interfaces for databases, when applied to an operator-specific benchmark dataset of expert-generated representative queries, with 66% execution accuracy.
