# A stochastic learning automata‐based solution for intrusion detection in vehicularad hocnetworks
Sudip Misra, Parimala Venkata Krishna, Kiran Isaac Abraham · Security and Communication Networks 2010 · https://doi.org/10.1002/sec.200 · relevance: medium · basis: abstract

**Problem:** A number of security concerns are associated with vehicularad hocnetworks (VANET) – some primarily related with the transmission issues between the vehicles and the base stations, while others related with the privacy of the end‐users. Security in VANET is of significant importance, considering the scale of the possible deployment of VANET and their role as a traffic manager.
**Approach:** In this paper, we propose an intrusion detection system (IDS) for a typical VANET scenario. We have designed this system considering the privacy issues involved with the identification of each vehicle.
**Tools and scale:** Not stated in abstract.
**Results:** Specifically, the proposed solution is capable of detecting up to around 90–95% of the malicious packets in the system.
