# A Connected and Autonomous Vehicle Reference Architecture for Attack Surface Analysis
Carsten R. Maple, Matthew S. Bradbury, Anhtuan Le, Kevin Ghirardello · Applied Sciences 2019 · https://doi.org/10.3390/app9235101 · relevance: medium · basis: abstract

**Problem:** Connected autonomous vehicles (CAVs) will be deployed over the next decade with autonomous functionalities supported by new sensing and communication capabilities. Such functionality exposes CAVs to new attacks that current vehicles will not face.
**Approach:** Therefore, we propose a reference architecture using a hybrid Functional-Communication viewpoint for attack surface analysis of CAVs, including the Devices, Edge and Cloud systems CAVs interact with.
