# Reputation-based awareness routing protocol for secure V2X communication
Fatma Salem · Cyber-Physical Systems 2025 · https://doi.org/10.1080/23335777.2025.2588760 · relevance: medium · basis: abstract

**Problem:** ABSTRACT Vehicle-to-everything (V2X) communication enables real-time interactions between vehicles and roadside infrastructure, supporting safety applications such as hazard detection and traffic awareness.
**Approach:** This paper presents a Reputation-based Awareness Routing protocol for Secure V2X communication (ReA-SR), which integrates pseudonym-based authentication and a trust scheme into clustering, selecting high-reputation vehicles as cluster heads.
**Tools and scale:** Analytical and simulation results show ReA-SR reduces latency, maintains packet drop below 5%, and achieves reception above 90%, improving security and efficiency for next-generation Intelligent Transportation Systems (ITS).
**Results:** Analytical and simulation results show ReA-SR reduces latency, maintains packet drop below 5%, and achieves reception above 90%, improving security and efficiency for next-generation Intelligent Transportation Systems (ITS).
