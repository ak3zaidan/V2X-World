# A Machine Learning-Based Framework for Real-Time Malicious Node Detection in VANETs
Rashmi Priyadarshini, Renu Bahuguna, Shashi Prakash Dwivedi et al. · International Symposium on Advanced Electrical and Communication Technologies (ISAECT) 2025 · https://doi.org/10.1109/isaect68904.2025.11318769 · relevance: medium · basis: abstract

**Problem:** It is essential to modern intelligent transportation systems that vehicles and infrastructure can communicate in real-time through vehicle ad-hoc networks (VANETs).
**Approach:** Using machine learning, this paper develops a real-time adaptive framework for detecting malicious nodes in VANETs. The proposed system effectively identifies anomalous behaviour even under evolving network conditions using adaptive random forests (ARFs) and k-nearest neighbours (KNNs).
**Tools and scale:** Simulated datasets have been evaluated using simulation environments such as SUMO and NS-3.
**Results:** Using this model, VANET environments can be secured in real-time, even under high attack intensities, demonstrating a scalable and efficient solution.
