# SSOV: A Single Sign-on Protocol for Accessing Vehicular Application Services with the Support of Secret Credential Management System
You-Wei Chang, Po-Ching Lin · International Conference on Supercomputing 2020 · https://doi.org/10.1109/ics51289.2020.00092 · relevance: high · basis: abstract

**Approach:** SSOV single sign-on built on the IEEE 1609.2 SCMS: vehicles log in to services anonymously using pseudonym certificates, single identity provider. (summarised from the abstract only)
