# Ensuring End-to-End Security With Fine-Grained Access Control for Connected and Autonomous Vehicles
Donghyun Yu, Sungho Lee, Ruei‐Hau Hsu et al. · IEEE Transactions on Information Forensics and Security 2024 · https://doi.org/10.1109/tifs.2024.3417292 · relevance: low · basis: abstract

**Problem:** As advanced V2X applications emerge in the connected and autonomous vehicle (CAV), the data communications between in-vehicle end-devices and outside nodes increase, which make the end-to-end (E2E) security to in-vehicle end-devices as the urgent issue to be handled.
**Approach:** Therefore, this paper proposes a practical and secure vehicular communication protocol for the E2E security based on a new attribute-based encryption (ABE) scheme.
**Tools and scale:** Not stated in the abstract.
**Results:** The protocol achieves the confidentiality, message authentication, identity anonymity, unlinkability, traceability, and reconfigurable outsourced computation, and this paper also shows the practical feasibility of the protocol via the performance evaluation.
**Limitations and future work (as stated by the authors):**
- However, the E2E security with fine-grained access control still remains as a challenging issue for resource-constrained end-devices since the existing security solutions require complicated key management and high resource consumption.
- In the ABE scheme, the outsourced computation is provided for encryption, and the computation cost for decryption constantly remains small, regardless of the number of attributes.
