# Cooperative cross layer detection for blackhole attack in VANET-OLSR
Raghad Baiad, Hadi Otrok, Sami Muhaidat, Jamal Bentahar · International Wireless Communications and Mobile Computing Conference (IWCMC) 2014 · https://doi.org/10.1109/iwcmc.2014.6906469 · relevance: low · basis: abstract

**Problem:** In this paper, we address the problem of detecting blackhole attack targeting the Multi Point Relays (MPRs), using Vehicular Ad hoc networks-Secure Optimized Link State Routing protocol (VANET-OLSR). In the literature, watchdog model was proposed to detect network related attacks.
**Approach:** In the literature, watchdog model was proposed to detect network related attacks. As a solution to improve the watchdog detection, we propose a cooperative intrusion detection system based on cross layer architecture, that correlates both MAC and network layers detections.
**Tools and scale:** Vehicular setting (VANET/IoV/V2X). Not detailed in the catalogued abstract (no integrated traffic, radio and SCMS simulation identified); see the paper for setup and scale.
**Results:** Simulation results corroborate that the use of cooperative cross layer design improves the detection percentage and minimizes the false positive rate.
