# Unified Physical Layer Network for Multiple Tasks based on Large Language Model
Tianyue Zheng, Linglong Dai · GLOBECOM 2025 - 2025 IEEE Global Communications Conference 2025 · https://doi.org/10.1109/globecom59602.2025.11432235 · relevance: low · basis: abstract

**Problem:** The recent advance of Large Language Models (LLMs) offers a promising approach to effectively improve the performance in different physical-layer (PHY) tasks.
**Approach:** To solve the problem, we propose a LLM-enabled multi-task PHY framework to unify multiple tasks with a single LLM by exploiting the excellent semantic understanding and generation capabilities of LLMs. The proposed design allows different wireless data types to be well aligned with the LLM input format.
