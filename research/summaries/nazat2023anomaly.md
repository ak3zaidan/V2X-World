# Anomaly Detection Framework for Securing Next Generation Networks of Platoons of Autonomous Vehicles in a Vehicle-to-Everything System
Sazid Nazat, Mustafa Abdallah · Proceedings of the 9th ACM Cyber-Physical System Security Workshop 2023 · https://doi.org/10.1145/3592538.3594274 · relevance: high · basis: abstract

**Problem:** We consider a security setting involving a platoon of autonomous vehicles (AVs) that commute from one place to another.
**Approach:** Such vehicle platooning is utilized to optimize the usage and safety of highways. We propose a dynamic framework for a network of platoons that captures both the communication between different platoons along with the communication between different AVs within the single platoon.
