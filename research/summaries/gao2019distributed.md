# A Distributed Network Intrusion Detection System for Distributed Denial of Service Attacks in Vehicular Ad Hoc Network
Ying Gao, Hongrui Wu, Binjie Song, Yaqia Jin et al. · IEEE Access 2019 · https://doi.org/10.1109/access.2019.2948382 · relevance: medium · basis: abstract

**Problem:** Security assurance in Vehicular Ad hoc Network (VANET) is a crucial and challenging task due to the open-access medium. One great threat to VANETs is Distributed Denial-of-Service (DDoS) attack because the target of this attack is to prevent authorized nodes from accessing the services.
**Approach:** To overcome these challenges, this paper proposes a distributed DDoS network intrusion detection system based on big data technology.
**Tools and scale:** In order to evaluate the accuracy of detection, the algorithm was evaluated and compared in the datasets, containing NSL-KDD and UNSW-NB15.
**Results:** In the network collection module, micro-batch data processing model is used to improve the real-time performance of traffic feature collection. The experimental results show that the proposed detection algorithm reached the accuracy rate of 99.95% and 98.75%, and the false alarm rate (FAR) of 0.05% and 1.08%, respectively, in two datasets.
**Limitations and future work (as stated by the authors):**
- Security assurance in Vehicular Ad hoc Network (VANET) is a crucial and challenging task due to the open-access medium.
- However, big data from VANETs poses serious challenges to DDoS attack detection since the detection system require scalable methods to capture, store and process the big data.
- To overcome these challenges, this paper proposes a distributed DDoS network intrusion detection system based on big data technology.
