# Energy-efficient edge based intrusion detection system using machine learning
Sanjay Kumar Sonker, Ashish Kumar, Manoj Kumar, Kamini, Prem Prakash Agrawal, Poonam Devi · 2025 2nd International Conference on Computational Intelligence, Communication Technology and Networking (CICTN) 2025 · https://doi.org/10.1109/cictn64563.2025.10932469 · relevance: medium · basis: abstract

**Problem:** Edge based computing’s primary goal is to enhance network performance by storing and processing data in proximity to the end user.
**Approach:** However, the rapid development of edge computing often overlooks security risks in powerful applications and large-scale computer systems. Security and privacy are essential prerequisites for both edge computing and the ecosystems built around it.
**Tools and scale:** Not stated in the abstract.
**Results:** This paper discusses the Edge based IDS designed specifically for edge computing with accuracy 99.77% to detect the attacks with 30% of malicious electric vehicle include in the simulation focusing on its relevant processes, features, and procedures.
