# Federated Learning Approach for Edge Application of Network Link Classification Based on Traffic Matrices
Nicolas André Alves Da Silva, C. A. V. Campos, S. D. de Lucena · IEEE Access 2026 · https://doi.org/10.1109/access.2026.3675110 · relevance: low · basis: abstract

**Problem:** Monitoring network links is an important task for providing network services, such as routing in Software-Defined Networks (SDNs).
**Approach:** To optimize this calculation, this article presents the NetLinkClassifier, which is a Machine Learning (ML) model that classifies a network link using a traffic matrix that contains all the end-to-end traffic demands of the network in a given time interval. The traffic matrix for the model input is assembled in a Multi-access Edge Computing (MEC) layer of the SDN, using traffic demand data from each SDN node.
