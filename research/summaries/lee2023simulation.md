# Simulation-Based Cybersecurity Testing and Evaluation Method for Connected Car V2X Application Using Virtual Machine
Dae-Hwi Lee, Chan-Min Kim, Hyun-Seok Song, Yong-hee Lee et al. · Italian National Conference on Sensors 2023 · https://doi.org/10.3390/s23031421 · relevance: high · basis: full text

**Problem:** No simulation evaluates V2X application-level security (1609.2) before road tests.
**Approach:** VM-based V2X simulation test platform with CANoe Option.Car2X and four security evaluation scenarios.
**Tools and scale:** Vector CANoe, virtual machines.
**Results:** Not stated in the abstract.
**Limitations and future work (as stated by the authors):**
- Need method to evaluate application-level security (misbehaviour processing) beyond conformity testing
- real-world tests have time/cost/safety issues
**Overlap with our engine:** partial — 1609.2 security testing in simulation; much smaller scope than our engine.
**Novelty implications:** None.
