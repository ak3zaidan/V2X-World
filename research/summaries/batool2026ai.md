# AI-Native Predictive Scheduling for Computing Power Networks: A Multi-Scale Learning Framework for Ultra-Low Latency 6G Applications
Iqra Batool, Mostafa M. Fouda, Zubair Md Fadlullah · IEEE Transactions on Network Science and Engineering 2026 · https://doi.org/10.1109/tnse.2026.3650877 · relevance: low · basis: abstract

**Problem:** Computing Power Networks (CPNs) represent a paradigm shift from traditional cloud-edge architectures to unified computing fabrics essential for sixth-generation (6G) wireless networks supporting ultra-low latency AI applications.
**Approach:** However, existing CPN frameworks rely on reactive resource management that cannot meet stringent latency requirements of time-critical workloads. This paper introduces ProactiveCPN, the first AI-native predictive scheduling framework that leverages multi-scale machine learning to anticipate system states and proactively manage AI task allocation in CPNs.
**Tools and scale:** Not stated in the abstract.
**Results:** Through comprehensive evaluation using ITU-R compliant 6G scenarios, ProactiveCPN significantly outperforms state-of-the-art reactive methods in average latency, deadline satisfaction, energy efficiency, and system throughput while maintaining robust performance across diverse mobility patterns and system loads.
