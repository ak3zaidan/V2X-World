# An intelligent intrusion detection system for external communications in autonomous vehicles
Khattab M. Ali Alheeti · Open Access at Essex (University of Essex) 2017 · https://www.semanticscholar.org/paper/525619c2488f8f48564c665efa65d1c5dca8919b · relevance: medium · basis: abstract

**Problem:** Advancements in computing, electronics and mechanical systems have resulted in the creation of a new class of vehicles called autonomous vehicles.
**Approach:** These vehicles function using sensory input with an on-board computation system. Self-driving vehicles use an ad hoc vehicular network called VANET.
**Tools and scale:** Not stated in the abstract.
**Results:** This has been achieved using fuzzification and artificial intelligence. The second contribution is the incorporation of the Integrated Circuit Metrics (ICMetrics) for improved security and privacy.
