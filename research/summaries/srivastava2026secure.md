# Secure Communication Using Blockchain in Vehicular Sensor Network
Sandeep Srivastava, Deepshikha Agarwal, B. Chaurasia · IEEE Sensors Journal 2026 · https://doi.org/10.1109/jsen.2026.3678320 · relevance: medium · basis: abstract

**Problem:** PKI scalability in vehicular sensor networks.
**Approach:** Blockchain key management with BLS signatures and three-layer identity-based key distribution.
**Tools and scale:** Simulations and real-world testbeds.
**Results:** +20% transaction frequency, +45% throughput, -50% block congestion.
