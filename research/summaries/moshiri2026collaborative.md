# A Collaborative Edge Intelligence Framework for SFC Provisioning via Language Models
Parisa Fard Moshiri, Xinyu Zhu, Poonam Lohan et al. · IEEE Transactions on Network and Service Management 2026 · https://doi.org/10.1109/tnsm.2026.3717489 · relevance: low · basis: abstract

**Problem:** As Software-Defined Networking (SDN) and Network Function Virtualization (NFV) enabled networks scale in size and complexity, monitoring and managing Service Function Chains (SFCs) under stringent latency and resource constraints becomes increasingly challenging.
**Approach:** Query decomposition is performed using a retrieval-augmented language model (RAG-LLM) and compared with a lightweight rule-based decomposition baseline.
**Tools and scale:** Not stated in the abstract.
**Results:** The resulting sub-queries are translated into Structured Query Language (SQL) using FLAN-T5. The results show that the rule-based edge pipeline achieves the lowest latency, reducing E2E latency by up to 78% compared to RAG-LLM and 18% compared to cloud execution under high workloads.
