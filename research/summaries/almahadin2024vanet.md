# VANET Network Traffic Anomaly Detection Using GRU-Based Deep Learning Model
Ghayth ALMahadin, Yassine Aoudni, Mohammad Shabaz, Anurag Vijay Agrawal et al. · IEEE Transactions on Consumer Electronics 2024 · https://doi.org/10.1109/tce.2023.3326384 · relevance: medium · basis: abstract

**Problem:** The rise of Vehicular Ad-hoc Networks (VANETs) has led to the growing significance in intelligent transportation systems. This research suggests a deep learning model for anomaly detection based on GRU over VANET network traffic to address this challenge.
**Approach:** This research suggests a deep learning model for anomaly detection based on GRU over VANET network traffic to address this challenge.
**Tools and scale:** The right anomaly detection technique basically depends on the labels that are present in the dataset.
**Results:** To further improve the accuracy of proposed model, a new semi-supervised technique for detecting VANET network activity anomalies called SEMI-GRU has been proposed. The results demonstrate that proposed GRU-based deep learning model outperforms existing methods in detecting network anomalies with low false positive rates.
