# Toward an Open Source Location Privacy Evaluation Framework for Vehicular Networks
David Eckhoff, Mykola Protsenko, Reinhard German · 2014 IEEE 80th Vehicular Technology Conference (VTC2014-Fall) 2014 · https://doi.org/10.1109/vtcfall.2014.6966211 · relevance: high · basis: abstract

**Problem:** Outline and present building blocks for a comprehensive open source location privacy evaluation framework to enable researchers to reproducibly assess the effectiveness of a given privacy protection algorithm.
**Approach:** We also present a proof of concept evaluation. By extending the well established Veins simulation framework [4] that couples the traffic simulator SUMO and the network simulator OMNeT++ we allow for an easy setup and integration with existing simulation scenarios or already implemented protocols.
**Tools and scale:** Not stated in the available text unless given above (topic: location privacy).
**Results:** By extending the well established Veins simulation framework [4] that couples the traffic simulator SUMO and the network simulator OMNeT++ we allow for an easy setup and integration with existing simulation scenarios or already implemented protocols.
**Limitations and future work (as stated by the authors):**
- We hope that our framework lowers the complexity of privacy evaluation and thereby makes certain protection measures more likely to be considered in future vehicular networks.

**Novelty implications:** Prior work on this exact mechanism; we cannot claim it as new. Open: integration with full radio/traffic stack, per-message ground truth, and safety outcomes in closed loop.
