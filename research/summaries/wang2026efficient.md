# An Efficient Post-Quantum Cross-Domain Authentication Scheme for 6G V2X Using Accelerated FrodoKEM
Jingfeng Wang, Yingying Yao · International Conference on Computer and Communication Systems (ICCCS) 2026 · https://doi.org/10.1109/icccs69761.2026.11613267 · relevance: high · basis: abstract

**Problem:** Unstructured-lattice PQ authentication is too slow for 6G V2X cross-domain authentication.
**Approach:** Cross-domain authentication using AVX2-accelerated FrodoKEM at RSUs; BAN logic proof. (summarised from the abstract only)
**Tools and scale:** Performance evaluation.
**Results:** Total authentication latency about 7.56 ms.
