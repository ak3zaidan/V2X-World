# STAF: Leveraging LLMs for Automated Attack Tree-Based Security Test Generation
Tanmay Khule, Stefan Marksteiner, Jose Alguindigue et al. · 23rd escar Europe : The World's Leading Automotive Cyber Security Conference 2025 2025 · https://doi.org/10.13154/294-13659 · relevance: low · basis: abstract

**Problem:** In modern automotive development, security testing is critical for safeguarding systems against increasingly advanced threats.
**Approach:** This paper introduces STAF (Security Test Automation Framework), a novel approach to automating security test case generation. Leveraging Large Language Models (LLMs) and a four-step self-corrective Retrieval-Augmented Generation (RAG) framework, STAF automates the generation of executable security test cases from attack trees, providing an end-to-end solution that encompasses the entire attack surface.
**Tools and scale:** Not stated in the abstract.
**Results:** Our results show significant improvements in efficiency, accuracy, scalability, and easy integration in any workflow, marking a substantial advancement in automating automotive security testing methodologies.
