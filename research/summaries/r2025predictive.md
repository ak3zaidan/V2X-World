# Predictive Modeling of 5G Control Channel Reliability Using Machine Learning on Realworld Dataset
S. R, S. S · 2025 Tenth International Conference on Science Technology Engineering and Mathematics (ICONSTEM) 2025 · https://doi.org/10.1109/iconstem65670.2025.11374834 · relevance: low · basis: abstract

**Problem:** This work proposes a novel hybrid machine learning framework predicting 5G network download speeds using Random Forest, XGBoost, and Support Vector Machine models.
**Approach:** The dataset used contained over 10,000 samples and numerous categorical features (location, network type, device model, carrier, and VONR enablement) which underwent preprocessing, label encoding, imputing missing values and standard scaling. The best performing model was Random Forest with an $\mathrm{R}^{2}$ of 0.93, RMSE of 4.85 Mbps and MAE of 3.12 Mbps.
**Tools and scale:** Mentions: 5G.
**Results:** The dataset was divided for training (80 %) and testing (20 %) and the models were evaluated using $\mathrm{R}^{2}$, RMSE and MAE. The results show that Random Forest and XGBoost, which are ensemble models, surpass the individual learners in predicting 5G performance.
