# DBO-Optimized Deep Hybrid Framework for DDoS Attack Detection in Vanets
K. Saranya, S. Ramakrishnan, A. Harees et al. · 2026 International Conference on Signal, Systems, and Computing for Next-Gen Automation (ICSSCNA) 2026 · https://doi.org/10.1109/icsscna68616.2026.11546973 · relevance: medium · basis: abstract

**Problem:** Vehicular Ad Hoc Networks (VANETs) are important components of intelligent transport systems because they facilitate real-time communication between vehicles, they are also susceptible to DDoS attacks because of their dynamic and open nature.
**Approach:** This paper presents a hybrid deep learning-based Intrusion Detection System (IDS) to improve the security of VANET environments. The proposed system will serve as a userfriendly, scalable solution for securing VANET communications.
**Tools and scale:** The Hybrid IDS performance is evaluated using the UNSW-NB15 dataset and deployed via a Stream lit-based web application to allow for real-time single and batch predictions.
**Results:** The Hybrid IDS uses Alex Net and Inception networks to extract spatial features from network traffic data and improve the detection of DDoS attacks by learning the temporal dependencies of the traffic flow using a Bi-directional Long Short-Term Memory (BiLSTM) network.
