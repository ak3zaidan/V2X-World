# IoT Vehicle Traffic Anomaly Detection Using Machine Learning Techniques: A Case Study with DAD Dataset
Himani Jain · Journal of Electrical Systems 2024 · https://journal.esrgroups.org/jes/article/view/5760 · relevance: medium · basis: abstract

**Problem:** The increasing growth of the Internet of Things (IoT) has significantly transformed various sectors, including transportation.
**Approach:** With the increasing number of connected vehicles, the need for effective traffic anomaly detection systems has become crucial for ensuring safety and efficiency on the roads.
**Tools and scale:** This study aims to address this need by employing Machine Learning (ML) techniques to detect anomalies in vehicle traffic, specifically using the Driver Anomaly Detection (DAD) dataset.
**Results:** The ML methods employed in this study include Logistic Regression (LR), Support Vector Machine (SVM), and Random Forest (RF), with RF showing the best performance with an accuracy of 94.27%. The RF model also exhibited the highest Area Under the Curve (AUC) value of 0.9813, outperforming existing studies.
