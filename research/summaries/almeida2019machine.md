# A Machine Learning Based Quality of Service Estimator for Aerial Wireless Networks
Eduardo Nuno Almeida, Kelwin Fernandes, Francisco Andrade, Pedro Silva et al. · 2019 International Conference on Wireless and Mobile Computing, Networking and Communications (WiMob) 2019 · https://doi.org/10.1109/wimob.2019.8923217 · relevance: medium · basis: abstract

**Problem:** Unmanned Aerial Vehicles (UAVs) acting as aerial Wi-Fi Access Points or cellular Base Stations are being considered to deploy on-demand network capacity in order to serve traffic demand surges or replace Base Stations. The ability to estimate the Quality of Service (QoS) for a given network setup may help in solving UAV placement problems.
**Approach:** This paper proposes a Machine Learning (ML) based QoS estimator, based on convolutional neural networks, which estimates the QoS for a given network by considering the UAV positions, the user positions and their offered traffic. We demonstrate the usefulness and applicability of the proposed QoS estimator using the ideal UAV placement algorithm.
