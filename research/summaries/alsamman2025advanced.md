# Advanced DDOS Attack Detection in Vanet Cloud Systems Using Secretary Bird Optimization and Machine Learning
Salsabil Alsamman, Alavikunhu Panthakkan, Amjad Gawanmeh · International Conference on Computational Intelligence and Knowledge Economy (ICCIKE) 2025 · https://doi.org/10.1109/iccike67021.2025.11318177 · relevance: medium · basis: abstract

**Problem:** This study proposes machine learning-based intrusion detection system optimized using Secretary Bird Optimization Algorithm (SBOA) to detect DDoS attacks in real-time.
**Approach:** The obtained results in this work showed that SBOA-RF is effective and practical as solution for protecting VANETs against DDoS attacks while at the same time maintaining real-time detection ability, which is needed for some critical applications.
**Tools and scale:** Network Simulator 2 (NS2) simulations were conducted with $20-50$ vehicles traveling at $60-100 ~\text{km} / \mathrm{h}$ over $2000 ~\mathrm{m} \times 500 ~\mathrm{m}$ area, testing scenarios with $10-25 \%$ malicious nodes.
**Results:** SBOA-optimized Random Forest achieved 99.78 % detection accuracy, 99.79 % precision, and 99.78% F1-score on 200,000 samples, outperforming baseline Random Forest (99.47 %), Decision Tree (99.12 %), and existing methods including PSO-based (99.65 %) and GA-based (99.58 %) approaches. Confusion matrix revealed only 88 misclassifications from 40,000 test samples, with balanced false positive and false negative rates of 0.22 % each.
