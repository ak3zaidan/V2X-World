# Emulating Vehicular Ad hoc Networks for Evaluation and Testing of Automotive Embedded Systems
Manuel Schiller, Alois Knoll · Proceedings of the Eighth EAI International Conference on Simulation Tools and Techniques 2015 · https://doi.org/10.4108/eai.24-8-2015.2261004 · relevance: high · basis: abstract

**Problem:** Repeatable large-scale evaluation of real automotive software in VANETs.
**Approach:** Virtualisation framework executing network and vehicle simulators synchronised with applications in virtual ECUs.
**Tools and scale:** Network + vehicle simulators, virtual ECUs.
**Results:** Large-scale experiments possible without loss of accuracy despite overhead.
