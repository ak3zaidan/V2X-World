# 5G V2X Misbehavior Detection as Edge Core Network Function Based on AI/ML
Hadi Yakan, Ilhem Fajjari, Nadjib Aitsaadi, Cedric Adjih · GLOBECOM 2023 - 2023 IEEE Global Communications Conference 2023 · https://doi.org/10.1109/globecom54140.2023.10437682 · relevance: high · basis: full text (abstract, introduction, evaluation and conclusion excerpts)

**Problem:** Protect 5G edge V2X application servers from position manipulation.
**Approach:** ORPC ML model plus collaborative edge model sharing attack ratios.
**Tools and scale:** 5G core emulation; VeReMi adapted to V2N.
**Results:** Accuracy 73% to 91%, collaborative 95%.
**Limitations and future work (as stated by the authors):**
- Dataset designed for VANET needed adjustment.
**Overlap with our engine:** partial — MBD in 5G V2N.
**Novelty implications:** None.
