# Large Language Models as Configuration Validators
Xinyu Lian, Yinfang Chen, Runxiang Cheng, Jie Huang et al. · International Conference on Software Engineering 2025 · https://doi.org/10.1109/icse55347.2025.00017 · relevance: medium · basis: abstract

**Problem:** Misconfigurations are major causes of software failures. Existing practices rely on developer-written rules or test cases to validate configuration values, which are expensive.
**Approach:** We present the first analysis on the feasibility and effectiveness of using LLMs for configuration validation. We empirically evaluate LLMs as configuration validators by developing a generic LLM-based configuration validation framework, named Ciri.
**Tools and scale:** Mentioned in abstract: LLM, field. (From the abstract only.)
**Results:** Our analysis (1) confirms the potential of using LLMs for configuration validation, (2) explores design space of LLM-based validators like Ciri, and (3) reveals open challenges such as ineffectiveness in detecting certain types of misconfigurations and biases towards popular configuration parameters.
