# Integrated Extensible Simulation Platform for Vehicular Sensor Networks in Smart Cities
Xiaolan Tang, Juhua Pu, Ke Cao, Yi Zhang, Zhang Xiong · International Journal of Distributed Sensor Networks 2012 · https://doi.org/10.1155/2012/860415 · relevance: high · basis: abstract

**Problem:** Need a general simulation environment for vehicular sensor networks in smart cities.
**Approach:** BHU-VSim with hierarchical entity structure, general data container, task scheduling, storage and importable routing protocols.
**Tools and scale:** Own simulator; real-time traffic monitoring instance.
**Results:** Practicality and accuracy demonstrated in an instance application (qualitative).
**Limitations and future work (as stated by the authors):**
- Presented as an initial attempt.
**Overlap with our engine:** partial — own integrated vehicular simulator.
**Novelty implications:** No impact.
