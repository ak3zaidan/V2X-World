# Developing malevolent node-based protection system against jamming attack in agent assisted CRN
Natasha Saini, Nitin Pandey, AJEET PAL SINGH · International Journal of Information and Computer Security 2020 · https://doi.org/10.1504/ijics.2020.108128 · relevance: medium · basis: abstract

**Problem:** Recent advancements in CRN realises many applications such as industrials, future fifth generation network, vehicular network and so on.
**Approach:** However, CRN is vulnerable to security attacks which are held on different layers of the network. Many research works are followed up on CRN in the security perspective but none of them is able to secure network from multiple attacks.
**Tools and scale:** Not stated in the abstract.
**Results:** SSDF attack detection is carried out using trust conscious attacker detection (TCAD) scheme in which improved k-means (IK-means) algorithm is involved for report analysis. Extensive experimental results show promising results in delay, packet delivery ratio, secrecy rate, signal to interference and noise ratio (SINR), and probability of false-alarm.
**Limitations and future work (as stated by the authors):**
- Recent advancements in CRN realises many applications such as industrials, future fifth generation network, vehicular network and so on.
- However, CRN is vulnerable to security attacks which are held on different layers of the network.
**Overlap with our engine:** partial — same area (V2X/vehicular security or networking) with a narrower, mechanism-level focus.
**Novelty implications:** Does not remove any of our claims beyond its specific mechanism; we cannot claim to be first on that mechanism. The joint closed-loop traffic/radio/PKI evaluation with counterfactual ground truth remains open as far as this abstract shows.
