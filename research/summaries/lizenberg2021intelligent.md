# Intelligent Co-Simulation Framework for Cooperative Driving Functions
Viktor Lizenberg, Mhd Redwan Alkurdi, Ulrich Eberle, Frank Koster · 2021 IEEE 17th International Conference on Intelligent Computer Communication and Processing (ICCP) 2021 · https://doi.org/10.1109/iccp53602.2021.9733618 · relevance: high · basis: abstract

**Problem:** Testing cooperative driving functions needs many scenarios.
**Approach:** Traffic-flow + vehicle-dynamics co-simulation with ML classifier to detect, generate and evaluate relevant test scenes.
**Tools and scale:** Co-simulation, ML classification; IMAGinE project.
**Results:** Testing focused on relevant scenarios with reasonable effort (qualitative).
