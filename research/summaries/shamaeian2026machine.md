# Machine Learning based Hybrid Trust Framework for Misbehaviour Detection in Vehicular Communication Networks
Nasrin Shamaeian, Dirk Pesch · 2026 IEEE Vehicular Networking Conference (VNC) 2026 · https://doi.org/10.1109/vnc69225.2026.11629106 · relevance: high · basis: abstract

**Problem:** Cryptography cannot stop erroneous data.
**Approach:** ML message classification plus socially aware Dempster-Shafer trust.
**Tools and scale:** VeReMi.
**Results:** Average precision up to 99% on five position attacks.
