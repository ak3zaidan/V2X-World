# Data-driven Network Simulation for Performance Analysis of Anticipatory Vehicular Communication Systems
Benjamin Sliwa, Christian Wietfeld · IEEE Access 2019 · https://doi.org/10.1109/access.2019.2956211 · relevance: high · basis: full text (extracted sections)

**Problem:** System-level network simulations of anticipatory vehicular communication differ from real-world behaviour.
**Approach:** Data-driven Network Simulation (DDNS): combines ML models trained on real measurements, plus crowdsensed connectivity maps, to replace system-level simulation.
**Tools and scale:** Validated against field measurements and system-level simulation; opportunistic vehicular data transfer.
**Results:** Massively faster result generation and closer agreement with field data than system-level simulation (numbers truncated).
**Limitations and future work (as stated by the authors):**
- Predictions rely on spatially aggregated past data for future locations.
**Overlap with our engine:** partial - learned vehicular network simulator replacing a conventional one (direction 3).
**Novelty implications:** Data-driven vehicular network simulation exists; counterfactual-aware surrogates with security state remain open.
