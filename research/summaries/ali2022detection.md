# Detection of Wormhole Attack in Vehicular Ad-hoc Network over Real Map using Machine Learning Approach with Preventive Scheme
Shahjahan Ali, Parma Nand, Shailesh Tiwari · DOAJ (DOAJ: Directory of Open Access Journals) 2022 · https://doi.org/10.22059/jitm.2022.86658 · relevance: low · basis: abstract

**Problem:** VANET (Vehicular Ad-hoc Network) is a developing technology, which is a combination of cellular technology, ad-hoc network & wireless LAN to improve the safety of vehicle as well as driver. VANET communication can be of two types, first one is broadcast and second one is unicast.
**Approach:** In this paper machine learning method is used to detect the wormhole assault in VANET’s multi-hop communication. We have created a scenario of VANET by using AODV routing protocol on NS-3.24.1 simulator, which utilizes the overall mobility traces generated by the simulator SUMO-0.32.0 to model the wormhole assault.
