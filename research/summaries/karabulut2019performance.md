# Performance Optimization by Using Artificial Neural Network Algorithms in VANETs
Muhammet Ali Karabulut, A. F. M. Shahen Shah, Haci Ilhan · 2019 42nd International Conference on Telecommunications and Signal Processing (TSP) 2019 · https://doi.org/10.1109/tsp.2019.8768830 · relevance: low · basis: abstract

**Problem:** The IEEE 802.11 standard provides specifications of medium access control (MAC) layer for VANET.
**Approach:** The performance can be optimized by optimizing contention window size. In this paper, to optimize the performance in VANETs three different artificial neural network (ANN) algorithms are used to find the optimum contention window (CW) size which are Particle Swarm Optimization (PSO), Differential Evolution Algorithm (DEA) and Artificial Bee Colony Algorithm (ABCA).
**Tools and scale:** Mentioned in abstract: simulation.
**Results:** The simulation results show that the ANN algorithms improve the communication reliability by increasing the throughput and decreasing the packet dropping rate (PDR).
