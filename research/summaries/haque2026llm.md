# LLM-Assisted Dynamic Threat Analysis for Attacker-Reachable Software Weaknesses in Autonomous Vehicles
Md. Wasiul Haque, Sagar Dasgupta, Mizanur Rahman, Md Rayhanur Rahman · arXiv (Cornell University) 2026 · https://arxiv.org/abs/2608.13450 · relevance: medium · basis: abstract

**Problem:** Confirming exploitability of attacker-reachable software weaknesses in Autoware.
**Approach:** Compiler-precise static analysis of 185 packages plus LLM-generated executable test artifacts for dynamic confirmation.
**Tools and scale:** Autoware open-source stack; 1,375 decision rules, 2,274 validation checks, 482 input-to-safety-output flows; 740 sampled weaknesses.
