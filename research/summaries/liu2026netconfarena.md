# NetConfArena: An Executable Benchmark for LLM Agents in Closed-Loop Network Configuration
Chang Liu, Xiaohui Xie, Xinyi Chen, Yong Cui · arXiv 2026 · https://arxiv.org/abs/2608.23179 · relevance: high · basis: full text (extracted sections)

**Problem:** Configuration benchmarks are static or oversimplified.
**Approach:** NetConfArena: emulated multi-device networks, compact action interface, hidden executable tests; LLM-assisted template pipeline.
**Tools and scale:** 480 instances from 96 templates; 3840 trajectories.
**Results:** Failures include task-specification adherence and planning gaps, not just command errors.
**Limitations and future work (as stated by the authors):**
- Future: trajectory-based learning and harness-level mechanisms.
**Overlap with our engine:** partial - closed-loop LLM agent benchmark on emulation.
**Novelty implications:** No effect on V2X.
