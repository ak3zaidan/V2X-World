# Cluster-Based Malicious Node Detection for False Downstream Data in Fog Computing-Based VANETs
Ke Gu, XinYing Dong, Xiong Li, WeiJia Jia · IEEE Transactions on Network Science and Engineering 2022 · https://doi.org/10.1109/tnse.2021.3139005 · relevance: medium · basis: abstract

**Problem:** In vehicular ad hoc networks (VANETs), many data protection schemes have been proposed to secure the data collection procedure, but few schemes focus on the downstream data transmission procedure. In some cluster-based data transmission schemes, if a legal cluster head node becomes malicious, then it is more likely to tamper with transferred data or provide false data easily.
**Approach:** In this paper, we propose a cluster-based malicious node detection scheme for false downstream data in fog computing-based VANETs, where the fog servers are used to detect the suspicious data and the malicious cluster head nodes. In our proposed scheme, we further construct a trajectory clustering method among vehicle nodes, in which the cluster head nodes and the corresponding edge monitoring nodes are accurately selected.
**Tools and scale:** Car-Hacking/CAN dataset (mentioned in abstract)
**Results:** Further, the experimental results show our proposed scheme is efficient for fog computing-based VANETs.
