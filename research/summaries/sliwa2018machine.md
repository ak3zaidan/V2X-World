# Machine Learning Based Context-Predictive Car-to-Cloud Communication Using Multi-Layer Connectivity Maps for Upcoming 5G Networks
Benjamin Sliwa, Robert Falkenberg, Thomas Liebig, Johannes Pillmann, Christian Wietfeld · 2018 IEEE 88th Vehicular Technology Conference (VTC-Fall) 2018 · https://doi.org/10.1109/vtcfall.2018.8690856 · relevance: high · basis: full text (extracted sections)

**Problem:** Resource-efficient car-to-cloud MTC uploads.
**Approach:** Mobility prediction plus ML channel-quality estimation via multi-layer connectivity maps to schedule transmissions.
**Tools and scale:** Field evaluation in a public LTE network; open-source code and data.
**Results:** Average data rate up to +194%, mean uplink power down up to 54%.
