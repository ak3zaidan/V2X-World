# Privacy-Preserving Object Detection with Secure Convolutional Neural Networks for Vehicular Edge Computing
Tianyu Bai, Song Fu, Qing Yang · Future Internet 2022 · https://doi.org/10.3390/fi14110316 · relevance: medium · basis: abstract

**Problem:** Privacy of sensor data and detection results offloaded to edge servers.
**Approach:** vePOD: additive secret sharing so each CNN layer of an object detector runs securely across edge servers.
**Tools and scale:** Object detection CNN; edge servers; no network simulator.
**Results:** Detection results recovered only by combining shares (no figures in abstract).
