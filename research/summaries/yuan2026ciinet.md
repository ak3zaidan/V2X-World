# CiiNet: Self-Iterative Performance Optimization for Dynamic Networks Based on Causal Inference and Interpretable Evaluation
Xun Yuan, Xiaonan Wang, Mina Kato, Fengxiao Tang et al. · IEEE Transactions on Networking 2026 · https://doi.org/10.1109/ton.2025.3626551 · relevance: medium · basis: abstract

**Problem:** Causal inference and root cause analysis play a crucial role in network performance evaluation and optimization by identifying critical parameters and explaining how the configuration parameters affect network key performance indicators (KPIs). Traditional performance evaluation methods can evaluate KPIs based on configuration parameters, but they are unable to explain how configuration parameters affect KPIs.
**Approach:** To address these challenges, we propose a self-iterative performance optimization method based on causal inference and interpretable network evaluation (CiiNet).
