# Performance Gains in V2X Experiments Using Distributed Simulation in the Veins Framework
Moritz Gütlein, Reinhard German, Anatoli Djanatliev · 2019 IEEE/ACM 23rd International Symposium on Distributed Simulation and Real Time Applications (DS-RT) 2019 · https://doi.org/10.1109/ds-rt47707.2019.8958671 · relevance: high · basis: abstract

**Approach:** Distributes multiple Veins instances coupled via HLA hybrid co-simulation.
**Tools and scale:** Veins, HLA.
**Results:** Higher speedup with increasing traffic load.
