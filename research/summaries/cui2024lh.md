# LH-IDS: Lightweight Hybrid Intrusion Detection System Based on Differential Privacy in VANETs
Jie Cui, Jietian Xiao, Hong Zhong, Jing Zhang et al. · IEEE Transactions on Mobile Computing 2024 · https://doi.org/10.1109/tmc.2024.3407709 · relevance: medium · basis: abstract

**Problem:** Vehicular Ad hoc Networks (VANETs) are vulnerable to various types of attacks. Intrusion Detection System (IDS) based on machine learning can effectively detect malicious network attacks in VANETs.
**Approach:** Therefore, we propose a lightweight hybrid IDS (LH-IDS) based on machine learning and DP. Additionally, the proposed model incurs only minimal CPU and memory overhead, making it a lightweight solution.
**Tools and scale:** Car-Hacking/CAN dataset (mentioned in abstract)
