# A Framework for Efficient and Optimal Network Selection for Vehicular Communication: A Hybrid ML-LLM Approach
Subhradip Debnath, Vijay M. Shrimal, Bhavna Nayyar · 2025 IEEE 17th International Conference on Computational Intelligence and Communication Networks (CICN) 2025 · https://doi.org/10.1109/cicn67655.2025.11368122 · relevance: low · basis: abstract

**Problem:** In this paper a new framework of intelligent network selection and optimization in vehicle communication system is described, which was created with the intention of assessing and advising on best network to use in Vehicle to everything (V2X) framework.
**Approach:** The suggested framework incorporates the latest machine learning approaches with Large Language Model (LLM) analysis using DeepSeek V3 to deliver detailed network performance analysis, real-time adaptive optimization, and intelligent decision-making to vehicular networks. The framework uses multi-dimensional network fingerprinting, hybrid anomaly detection and uncertainty-aware decision making to perform better than the current solutions.
**Tools and scale:** Not stated in the abstract.
**Results:** The framework uses Deepseek V3 model to discover and analyze different KPI's of the network and has provided a network selection accuracy above 96% with a network type detection above 98%.
