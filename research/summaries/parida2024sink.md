# Sink-Hole Attack Detection in VANET using Machine Learning Techniques
Debapriya Parida, Urmila Bhanja, Manish Okade · 2024 6th International Conference on Computational Intelligence and Networks (CINE) 2024 · https://doi.org/10.1109/cine63708.2024.10880882 · relevance: medium · basis: abstract

**Problem:** Vehicular Ad-hoc Networks (VANETs) have come up as a revolutionary technology for enabling intelligent transportation systems and enhancing road safety.
**Approach:** However, the open and decentralized character of VANETs renders them unsafe to various security threats, including sinkhole attacks, where the malicious nodes hijack and redirect network traffic. This work investigates the application of Machine Learning(ML) techniques for developing an effective Intrusion Detection System (IDS) to identify sinkhole attacks in VANETs.
