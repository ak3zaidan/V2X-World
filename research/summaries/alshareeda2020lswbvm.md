# LSWBVM: A Lightweight Security Without Using Batch Verification Method Scheme for a Vehicle Ad Hoc Network
Mahmood A. Al-Shareeda, Mohammed Anbar, Murtadha A. Alazzawi, S. Manickam et al. · IEEE Access 2020 · https://doi.org/10.1109/access.2020.3024587 · relevance: medium · basis: abstract

**Problem:** Recently, Vehicle Ad Hoc Networks (VANETs) have been increasingly developed in Intelligent Transportation Systems (ITSs). However, VANETs are vulnerable to security issues because of the open-medium nature of Vehicle-To-Vehicle (V2V) and Vehicle-To-Infrastructure (V2I) communication.
**Approach:** In this article, a Lightweight Security Without Using Batch Verification Method (LSWBVM) scheme is proposed based on Elliptic Curve Cryptography (ECC).
**Tools and scale:** BAN logic proves that the LSWBVM achieves the security goals to mutually authenticate between the nodes.
**Results:** BAN logic proves that the LSWBVM achieves the security goals to mutually authenticate between the nodes.
