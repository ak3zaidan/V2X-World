# Visible Light Communication Module: An Open Source Extension to the ns3 Network Simulator With Real System Validation
Adel Aldalbahi, Michael Rahaim, Abdallah Khreishah, Moussa Ayyash et al. · IEEE Access 2017 · https://doi.org/10.1109/access.2017.2759779 · relevance: low · basis: abstract

**Problem:** The emergence of new physical media such as optical wireless and the ability to aggregate these new media with legacy networks motivate the study of heterogeneous network performance, especially with respect to the design of protocols to best exploit the characteristics of each medium.
**Approach:** The proposed ns3 module has been developed based on existing models for intensity modulated LED signals operating as lighting units transmitting to optical receivers at indoor scales (meters).
**Tools and scale:** Mentions: ns3, simulation (details not in abstract).
**Results:** Results indicate good correspondence between the simulated and actual test bed performance. Subsequently, we demonstrate how the VLC module can be used to predict the performance of a hybrid Wi-Fi/VLC network simulated using the ns3 environment with UDP, TCP, and combined network traffic.
