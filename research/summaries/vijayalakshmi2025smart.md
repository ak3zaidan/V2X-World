# Smart parking: intelligent intrusion detection system in VANET enabled car parking system
S. Vijayalakshmi, S. Bose, G. Logeswari, N. Maheswaran · Automatika 2025 · https://doi.org/10.1080/00051144.2025.2476802 · relevance: medium · basis: abstract

**Problem:** Smart Parking is an innovative intelligent Intrusion Detection System (IDS) designed for smart car parking in Vehicular Ad-Hoc Network (VANET) environments. In today's digital era, smart parking technologies leverage sensor data, cameras, and Internet of Things (IoT) devices to efficiently manage parking spaces.
**Approach:** To address this challenge, a Machine Learning (ML)-driven IDS is proposed for DDoS attack detection in the smart parking system. The proposed IDS was simulated and evaluated across various performance metrics.
**Tools and scale:** Car-Hacking/CAN dataset, deep learning (mentioned in abstract)
**Results:** Results indicate that the Long Short-Term Memory (LSTM) model achieved 97% accuracy in detecting DDoS attack.
