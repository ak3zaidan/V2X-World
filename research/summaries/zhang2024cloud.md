# Cloud Control with Communication Delay Prediction for Intelligent Connected Vehicles*
Xinrui Zhang, Lu Xiong, Peizhi Zhang, Bo Leng et al. · 2024 IEEE Intelligent Vehicles Symposium (IV) 2024 · https://doi.org/10.1109/iv55156.2024.10588607 · relevance: medium · basis: abstract

**Problem:** In this paper, we propose a cloud control method with communication delay prediction for intelligent connected vehicles (ICVs), which not only constructs a prediction model using real-world 5G communication delay data, but also evaluate the effectiveness of the cloud control method considering delay in typical application scenarios. Firstly, for the application data interaction of 5G vehicle-to-network-to-vehicle (V2N2V) full-link, we collect a large amount of communication delay data through vehicle test.
**Approach:** Then, a novel data-driven delay prediction method based on the Long Short-Term Memory (LSTM) network is introduced.
**Tools and scale:** Mentioned in abstract: 5G, real-world. (From the abstract only.)
**Results:** The test results show that our method can not only achieve high delay prediction accuracy, but also significantly reduce vehicle velocity fluctuations and avoid collisions.
