# Real-Time Detection of Malicious Nodes Using Poplar Optimized Sparsity-Aware Network for Improving VANET Security
R. Ezumalai, D. Santhakumar · 2025 3rd International Conference on Communication, Security, and Artificial Intelligence (ICCSAI) 2025 · https://doi.org/10.1109/iccsai64074.2025.11064456 · relevance: medium · basis: abstract

**Problem:** Vehicular Ad Hoc Networks (VANETs) constitute a fundamental part of the Intelligent Transportation Systems since they allow vehicle to vehicle, and vehicle to infrastructure communications.
**Approach:** However, due to the nature of Mobile Ad hoc Networks and high mobility of VANETs, they are vulnerable to malicious node attacks which adversely affect the reliability of the network and road safety. Current detection frameworks are not optimized for real-time and can be computationally expensive, along with having high false positives.
**Tools and scale:** Not stated in the abstract.
**Results:** In this work Real-Time Detection of Malicious Nodes using Poplar optimized Sparsity-Aware Network for Improving VANET Security, a real-time malicious node identification using Deep Sparsity-Aware Neural Network (DS-ANN) with Reformed Poplar Optimization (RePO) is performed. The goal is to improve detection performance and minimize computations to achieve better scalability while being suitable for various VANET environments.
