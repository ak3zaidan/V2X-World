# Securing Vehicle-to-Grid Networks: A Bio-Inspired Intrusion Detection System
Mekkaoui Kheireddine, Mansour Mekour, Teggar Hamza · Scientia Iranica 2024 · https://doi.org/10.24200/sci.2024.64239.8820 · relevance: medium · basis: abstract

**Problem:** The Vehicle-to-Grid (V2G) network enables electric vehicles (EV) to connect and exchange both energy and data with the Smart Grid (SG), thus ensuring bidirectional communication and contributing to environmental protection.
**Approach:** However, the V2G network faces various security challenges, including data integrity, the security of electrical systems, physical protection of charging systems, data confidentiality, and system interoperability. Therefore, it is crucial to implement appropriate security mechanisms.This paper proposes a bio-inspired intrusion detection system (IDS) based on machine learning to predict and mitigate attacks on V2G network.
**Tools and scale:** Not stated in the abstract.
**Results:** Simulations conducted using the MiniV2G simulator show that the proposed IDS achieves a detection accuracy of 98.93%, thereby improving the reliability of the V2G network for users and offering better protection for electric vehicle charging stations against DoS and MitM attacks.
