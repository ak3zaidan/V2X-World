# AgentSUMO: An Agentic Framework for Interactive Simulation Scenario Generation in SUMO via Large Language Models
Minwoo Jeong, Jeeyun Chang, Yoonjin Yoon · arXiv 2025 · https://arxiv.org/abs/2511.06804 · relevance: high · basis: full text (extracted sections)

**Problem:** SUMO scenario building needs expertise; user requests are abstract and incomplete.
**Approach:** AgentSUMO: LLM agent with an Interactive Planning Protocol that infers missing parameters, plans and executes SUMO workflows, with state-aware XML context and prompt caching.
**Tools and scale:** SUMO.
**Results:** Not extracted.
**Limitations and future work (as stated by the authors):**
- Existing LM frameworks are imperative and command-driven (addressed).
**Overlap with our engine:** partial - LLM agent configuring a traffic simulator from natural-language intents, similar to our LLM agent's role; traffic only.
**Novelty implications:** LLM agents for SUMO scenario generation exist; cross-layer V2X/PKI configuration and analysis remain ours.
