# Privacy-Preserving Public Cloud Audit Scheme Supporting Dynamic Data for Unmanned Aerial Vehicles
Jiasen Liu, Xu An Wang, Zhiquan Liu et al. · IEEE Access 2020 · https://doi.org/10.1109/access.2020.2991033 · relevance: low · basis: abstract

**Problem:** As one of the most popular applications in recent years, cloud storage has been gradually integrated into all walks of life.
**Approach:** For this reason, we propose a public cloud audit scheme that supports dynamic data and privacy protection based on distributed string equality check protocol and Merkle-hash tree multi-level index structure.
**Tools and scale:** Not stated in the abstract.
**Results:** First of all, a third-party server (TPS) is set between the cloud service provider and users, which complete digital signature, integrity auditing, and data dynamic operations significantly in place of users to reduce the local computing cost. Secondly, to further improve the security of the scheme, TPS implement signature for encrypted data based on the distributed string equality check protocol.
