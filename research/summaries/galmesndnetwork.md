# Network modeling using graph neural networks
Miquel Ferriol Galmés ·  None · https://doi.org/10.5821/dissertation-2117-422057 · relevance: medium · basis: abstract

**Problem:** (English) Network modeling is central to the field of computer networks. Models are useful in researching new protocols and mechanisms, allowing administrators to estimate their performance before their actual deployment in production networks.
**Approach:** Network models also help to find optimal network configurations, without the need to test them in production networks.
**Tools and scale:** Arguably, the most prevalent way to build these network models is through the use of discrete event simulation (DES) methodologies which provide excellent accuracy.
**Results:** Modelos de tráfico: modelar con precisión patrones de tráfico realistas, que exhiben una fuerte autocorrelación y colas pesadas, sigue siendo un desafío para las soluciones basadas en GNN. 3. El desafío radica en diseñar GNN capaces de realizar estimaciones precisas en redes invisibles, que abarquen diferentes topologías, tráfico y configuraciones. 4.
