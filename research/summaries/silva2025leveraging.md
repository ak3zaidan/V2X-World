# Leveraging GNNs for Intent-Driven 5G RAN Optimization in Autonomous Networks
Andrey Silva, Dagnachew Azene Temesgene, Aldebaro Klautau, Rebecca Aben-Athar, Cleverson Nahum · IEEE Access 2025 · https://doi.org/10.1109/access.2025.3624754 · relevance: low · basis: abstract

**Problem:** Intent-based networking (IBN) is a key paradigm for enabling autonomous networks by abstracting complex manual configurations into high-level intents.
**Approach:** In this context, predicting the impact of configuration and topology changes is critical for ensuring efficient resource allocation and resolving conflicts in networks with shared and constrained resources. Graph Neural Networks (GNNs) have emerged as a powerful tool for modeling network structures and processing relational data, making them well-suited for predictive tasks in IBN.
**Tools and scale:** Mentioned in abstract: 5G.
**Results:** In this paper, we propose an improved GNN-based framework for predicting Key Performance Indicators (KPIs) in a fifth-generation (5G) Ran Access Network (RAN) within an IBN architecture, implementing state of the art features into the intent system, such as utility function as a means of user satisfaction, and standardized optional negotiation operations. Through extensive experimentation with different network configurations, we demonstrate that the GNN-based model in addition to the information of utility functions provides results close to the optimal solution, being able to balance between conflicting intent targets, and outperforming baseline approaches providing higher user satisfaction rate.
