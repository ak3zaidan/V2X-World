# Hybrid DNN-BiLSTM-aided intrusion detection and trust-clustering and routing-based intrusion prevention system in VANET
P. V. Sontakke, N. Chopade · Journal of Control and Decision 2023 · https://doi.org/10.1080/23307706.2023.2212684 · relevance: medium · basis: abstract

**Problem:** This paper focuses on developing an intrusion prevention and detection Vehicular Ad Hoc Network system by expert systems. The node data are composed of online sources.
**Approach:** The gathered node data is fed to the extraction phase which can be done by using the autoencoder model. The extraction of features was given to the selection of feature stage to select the optimal features using the Beetle-Whale Swarm Optimization.
**Tools and scale:** Car-Hacking/CAN dataset, deep learning (mentioned in abstract)
