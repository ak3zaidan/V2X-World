# Intelligent Misbehavior Detection System for Detecting False Position Attacks in Vehicular Networks
Faisal Hawlader, Abdelwahab Boualouache, Sebastien Faye, Thomas Engel · 2021 IEEE International Conference on Communications Workshops (ICC Workshops) 2021 · https://doi.org/10.1109/iccworkshops50388.2021.9473606 · relevance: high · basis: abstract

**Problem:** ML misbehaviour detectors use many features, increasing detection time for position falsification.
**Approach:** ML-based MDS using only received positions; six classical classifiers compared with supervised learning.
**Tools and scale:** Trained/tested on a public dataset (VeReMi-type), validated by simulation.
**Results:** Almost 100% accuracy detecting position falsification attacks.
**Limitations and future work (as stated by the authors):**
- None stated in abstract.
**Overlap with our engine:** partial — position-falsification detection on VeReMi-style data; offline, open loop.
**Novelty implications:** Offline ML position detection is saturated; in-loop consequences remain open.
