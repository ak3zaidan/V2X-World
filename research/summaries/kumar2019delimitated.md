# Delimitated Anti Jammer Scheme for Internet of Vehicle: Machine Learning Based Security Approach
Sunil Kumar, Karan Singh, Sushil Kumar, Omprakash Kaiwartya, Yue Cao, Huan Zhou · IEEE Access 2019 · https://doi.org/10.1109/access.2019.2934632 · relevance: medium · basis: abstract

**Problem:** Recently, Internet of vehicles (IoV) has witnessed significant research and development attention in both academia and industries due to the potential towards addressing traffic incidences and supporting green mobility. With the growing vehicular network density, jamming signal centric security issues have become challenging task for IoV network designers and traffic applications developers.
**Approach:** In this context, this paper proposes a machine learning oriented as Delimitated Anti Jamming protocol for vehicular traffic environments.
