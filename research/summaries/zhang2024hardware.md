# Hardware Secure Module Based Lightweight Conditional Privacy-Preserving Authentication for VANETs
Zihou Zhang, Jiangtao Li, Yufeng Li, Chenhong Cao et al. · IEEE Transactions on Information Forensics and Security 2024 · https://doi.org/10.1109/tifs.2024.3412418 · relevance: medium · basis: abstract

**Problem:** High computation and lack of forward security for system secret key updates in HSM-based CPPA.
**Approach:** HSM-based lightweight CPPA; precomputation inside HSM; SSK update via identity-based batch multi-signature, no single trusted authority.
**Tools and scale:** Formal proof and performance analysis.
**Results:** Lower computation cost (no figures in abstract).
