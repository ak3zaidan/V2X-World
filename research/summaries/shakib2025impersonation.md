# Impersonation Attack Using Quantum Shor’s Algorithm Against Blockchain-Based Vehicular Ad-Hoc Network
K. Shakib, Mizanur Rahman, Mhafuzul Islam, Mashrur Chowdhury · IEEE transactions on intelligent transportation systems (Print) 2025 · https://doi.org/10.1109/tits.2025.3534656 · relevance: high · basis: abstract

**Problem:** Blockchain-based VANETs using RSA signatures vulnerable to quantum attack.
**Approach:** Impersonation attack via Shor's algorithm on RSA signatures in blockchain VANET.
**Tools and scale:** OMNeT++/Veins/SUMO with INET V2X extension; IBM Qiskit.
**Results:** Impersonation attack feasible; compromises blockchain trust chain.
