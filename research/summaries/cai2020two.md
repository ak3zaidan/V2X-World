# Two-Party Privacy-Preserving Set Intersection with FHE
Yunlu Cai, Chunming Tang, Qiuxia Xu · Entropy 2020 · https://doi.org/10.3390/e22121339 · relevance: low · basis: abstract

**Problem:** A two-party private set intersection allows two parties, the client and the server, to compute an intersection over their private sets, without revealing any information beyond the intersecting elements.
**Approach:** We present a novel private set intersection protocol based on Shuhong Gao’s fully homomorphic encryption scheme and prove the security of the protocol in the semi-honest model.
