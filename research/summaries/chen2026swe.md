# SWE-Bench 5G: Benchmarking AI Coding Agents on Telecom Network Engineering Tasks
Jiao Chen, Jianhua Tang, Xiaotong Yang, Zuohong Lv · arXiv 2026 · https://arxiv.org/abs/2604.26278 · relevance: medium · basis: abstract

**Problem:** Unknown whether coding agents handle 5G core software tasks.
**Approach:** SWE-Bench 5G: tasks from three open-source 5G projects in Docker with fail-to-pass tests; spec context.
**Tools and scale:** Four LLMs.
**Results:** Diagnosis rates above 91%, resolve rates 10%-30%; spec injection helps.
