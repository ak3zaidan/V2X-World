# A Data-Driven Misbehavior Detection System for Connected Autonomous Vehicles
Ankur Sarker, Haiying Shen · Proceedings of the ACM on Interactive Mobile Wearable and Ubiquitous Technologies 2018 · https://doi.org/10.1145/3287065 · relevance: high · basis: abstract

**Problem:** Accurate, real-time false alert detection in CAV V2V.
**Approach:** Each CAV predicts alerting vehicle's driving state with an RNN-based Gaussian-mixture Mixture Density Network plus an extended Krauss model, then checks consistency with reported state.
**Tools and scale:** Real driving data from 29 participants; SUMO.
**Results:** Higher false-information detection rate than existing systems across alert scenarios.
**Limitations and future work (as stated by the authors):**
- None stated in abstract.
**Overlap with our engine:** partial — behaviour-model-based plausibility using traffic model.
**Novelty implications:** Learned driving models for plausibility exist.
