# NetLLMBench: A Benchmark Framework for Large Language Models in Network Configuration Tasks
Kaan Aykurt, Andreas Blenk, Wolfgang Kellerer · 2024 IEEE Conference on Network Function Virtualization and Software Defined Networks (NFV-SDN) 2024 · https://doi.org/10.1109/nfv-sdn61811.2024.10807499 · relevance: high · basis: abstract

**Problem:** No systematic evaluation of LLMs in network configuration.
**Approach:** NetLLMBench: closed loop of prompt engineering and network emulation that validates LLM-produced configurations.
**Tools and scale:** Network emulation.
**Results:** Foundational benchmarks (no numbers in abstract).
**Limitations and future work (as stated by the authors):**
- None stated.
**Overlap with our engine:** partial - LLM plus emulator in a closed loop, analogous to our LLM agent configuring and checking simulator runs.
**Novelty implications:** LLM-with-emulator validation loops exist for routers; not for V2X simulators.
