# Exploring Real-Time Malicious Behaviour Detection in VANETs
Hamideh Baharlouei, Adetokunbo Makanju, Nur Zincir-Heywood · Proceedings of the Int'l ACM Symposium on Design and Analysis of Intelligent Vehicular Networks and Applications 2023 · https://doi.org/10.1145/3616392.3623412 · relevance: low · basis: abstract

**Problem:** Vehicular ad hoc networks (VANETs) are a fundamental compo- nent of intelligent transportation systems, using real-time data from inter-connected vehicles to provide us faster and safer trips. However, these benefits raise a number of security challenges that need to be solved.
**Approach:** This paper is proposing a real time malicious be- haviour detection system that uses statistical and machine learning methods to detect malicious vehicles involved in Distributed Denial- of-Service (DDoS) attacks.
