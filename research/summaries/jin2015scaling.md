# Scaling VANET security through cooperative message verification
Hongyu Jin, Panos Papadimitratos · 2015 IEEE Vehicular Networking Conference (VNC) 2015 · https://doi.org/10.1109/vnc.2015.7385588 · relevance: medium · basis: abstract

**Problem:** VANET security introduces significant processing overhead for resource-constrained On-Board Units (OBUs). Here, we propose a novel scheme that allows secure Vehicular Communication (VC) systems to scale well beyond network densities for which existing optimization approaches could be workable, without compromising security (and privacy).
