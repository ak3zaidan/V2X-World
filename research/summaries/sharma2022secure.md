# Secure authentication and session key management scheme for Internet of Vehicles
Nishant Sharma, Naveen Chauhan, Narottam Chand et al. · Transactions on Emerging Telecommunications Technologies 2022 · https://doi.org/10.1002/ett.4451 · relevance: low · basis: abstract

**Problem:** Abstract Internet of Vehicles (IoV) is an internet enabled connected network of vehicles that provide services more effectively to its users via data sharing and communication with other vehicles and objects in the network.
**Approach:** We have also performed a formal security analysis of the scheme using the widely accepted AVISPA tool.
**Tools and scale:** Network simulation and communication cost comparisons show that SASM‐IoV is better in terms of different network parameters and provides better security with lower costs when compared to similar security schemes.
**Results:** Use of fog servers to create a vehicular cloud which is connected to a primary cloud server is another effective technique that gives better performance by achieving better cooperation between the vehicular cloud and the internet.
