# Robust detection framework for adversarial threats in Autonomous Vehicle Platooning
Stephanie Ness · Frontiers in Big Data 2025 · https://doi.org/10.3389/fdata.2025.1617978 · relevance: high · basis: abstract

**Problem:** Introduction The study addresses adversarial threats in Autonomous Vehicle Platooning (AVP) using machine learning.
**Approach:** Methods A novel method integrating active learning with RF, GB, XGB, KNN, LR, and AdaBoost classifiers was developed. Results Random Forest with active learning yielded the highest accuracy of 83.91%.
