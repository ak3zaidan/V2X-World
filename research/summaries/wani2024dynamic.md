# Dynamic Anonymous Quantum-Secure Batch-Verifiable Authentication Scheme for VANET
Nahida Majeed Wani, Girraj Kumar Verma, Vinay Chamola · IEEE Transactions on Consumer Electronics 2024 · https://doi.org/10.1109/tce.2024.3453953 · relevance: high · basis: abstract

**Problem:** Batch-verifiable VANET authentication is number-theoretic (quantum-vulnerable) and multiple pseudonyms cost storage.
**Approach:** Lattice-based dynamic anonymous batch-verifiable authentication using a fuzzy extractor instead of stored pseudonyms.
**Tools and scale:** Random-oracle proofs; performance evaluation.
