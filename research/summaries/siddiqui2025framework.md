# A Framework for Malicious Node Detection in VANETs using Machine Learning Approaches
Nazish Siddiqui · Journal of Information Systems Engineering & Management 2025 · https://doi.org/10.52783/jisem.v10i42s.7872 · relevance: medium · basis: abstract

**Problem:** Vehicular Ad-hoc Networks (VANETs) are crucial for enhancing road safety, enabling autonomous driving, and supporting efficient traffic management.
**Approach:** However, the open and highly dynamic nature of VANETs makes them vulnerable to various cyber threats posed by malicious nodes, including Sybil attacks, spoofing, and denial-of-service (DoS) attacks. This paper presents a novel hybrid detection framework that combines machine learning with a trust-based model to enhance malicious node detection in VANETs.
**Tools and scale:** Not stated in the abstract.
**Results:** By integrating these approaches, the framework provides robust, adaptive, and precise detection capabilities, effectively minimizing false positives and improving resilience against emerging threats. The proposed hybrid detection system significantly improves VANET security, offering an efficient and reliable solution for detecting and mitigating malicious nodes in complex vehicular networks.
