# Assessment of Novel V2X Applications Using a Simulation Platform
Samer Rajab, Radovan Miucic · SAE Technical Paper Series 2021 · https://doi.org/10.4271/2021-01-0115 · relevance: high · basis: abstract

**Problem:** V2X application validation is costly and naturalistic penetration is low.
**Approach:** Modified CARLA with V2X interface to an external OBU in the loop; EVA and HBA use cases; GPS inaccuracy tolerance test.
**Tools and scale:** CARLA, real OBU.
**Results:** True positive rate above 97% and false negative below 1% for EVA and HBA.
