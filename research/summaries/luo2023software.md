# Software defined network‐based multipath state‐aware routing with traffic prediction in satellite network
Yonghua Luo, Qian Ning, Bingcai Chen, Xinzhi Zhou, Linyu Huang · Transactions on Emerging Telecommunications Technologies 2023 · https://doi.org/10.1002/ett.4819 · relevance: low · basis: abstract

**Problem:** AbstractUneven traffic demand in satellite networks can lead to link congestion and influence network communication quality.
**Approach:** To tackle this problem, we propose a state‐aware routing algorithm based on traffic prediction to disperse network traffic. Reducing the onboard processing requirements, the routing algorithm in this paper introduces a software‐defined network to decouple the control plane and data plane of the satellite network.
**Tools and scale:** Mentioned in abstract: simulation.
**Results:** Based on the routing algorithm in this paper, multipath routing is designed to reduce the probability of link congestion by dispersing each end‐to‐end traffic. The simulation results demonstrate that the routing algorithm in this paper reduces the number of congestion links and balances the load distribution.
