# Mitigating Denial of Service Attacks in Software Defined Vehicular Networks
Gabriel de Biasi · Americanae (AECID Library) 2017 · http://hdl.handle.net/1843/JCES-AVPGMC · relevance: medium · basis: abstract

**Problem:** Software Defined Vehicular Network (SDVN) is a new network architecture inspired by the well-known Vehicular Ad Hoc Network (VANET), applying the concepts of Software Defined Network (SDN).
**Approach:** The SDVN proposes a complete data flow management by a module that controls the routing actions. We presented two SDVN architecture proposals: (1) Centralized mode, where there is only one controller and the vehicles use LTE and WAVE as interfaces communication and (2) distributed mode, where there are several controllers installed in RSUs and uses only WAVE communication.
