# 5G Radio Cell Performance Prediction Based on Knowledge Graph Fusion with Neural Network
Jakub Mazguła, Dariusz Król, Ireneusz Jabłoński · 2025 International Conference on Modeling, Analysis and Simulation of Wireless and Mobile Systems (MSWiM) 2025 · https://doi.org/10.1109/mswim67937.2025.11309040 · relevance: medium · basis: abstract

**Problem:** Data-driven 5G cell performance prediction ignores expert knowledge.
**Approach:** Knowledge graph of configuration dependencies fused into a regression model.
**Tools and scale:** Live 5G network data.
**Results:** Outperforms reference model; identifies impactful configuration elements.
