# Malicious node identification routing and protection mechanism for vehicular ad-hoc network against various attacks
Zaid A. Abdulkader, Azizol Abdullah, Mohd Taufik Abdullah, Zuriati Ahmad Zukarnain · International Journal of Networking and Virtual Organisations 2018 · https://doi.org/10.1504/ijnvo.2018.095419 · relevance: medium · basis: abstract

**Problem:** Vehicular ad-hoc network (VANET) is a promising approach that provides safety measures and other application to the drivers on the vehicles.
**Approach:** The focus of VANETs is to fulfil user's requirements on road side area which increases the safe and comfortable journey for users. It provides good communication like mobile ad-hoc network (MANET) when there is no intruders exist in the network.
