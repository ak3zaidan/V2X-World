# A2FGAN-T-MobileNetV3: A Lightweight Intrusion Detection System Based on Sensor Data for Vehicular Environments
Junyi Deng, Zhengzhi Ni, Jiayan Wen, Qiaobin Liu · venue unknown 2025 · https://doi.org/10.36227/techrxiv.175416014.45390521/v1 · relevance: medium · basis: abstract

**Problem:** Considering the diverse and complex nature of attacks in intelligent vehicular systems, this paper presents a sensor-driven data processing framework for intrusion detection, targeting both intra-vehicle CAN networks and external communication traffic.
**Approach:** The proposed method employs an A2FGANbased module to perform targeted data augmentation on imbalanced sensor-derived datasets, enhancing the representation of minority class attacks. An optimized lightweight MobileNetV3 model, embedded with model pruning and Triplet Attention mechanisms, is introduced to improve detection performance while maintaining low computational overhead-making it suitable for deployment on resource-constrained in-vehicle sensor or edge computing units.
**Tools and scale:** Not stated in the abstract.
**Results:** An optimized lightweight MobileNetV3 model, embedded with model pruning and Triplet Attention mechanisms, is introduced to improve detection performance while maintaining low computational overhead-making it suitable for deployment on resource-constrained in-vehicle sensor or edge computing units. The system integrates both feature enhancement and data-level balancing to improve detection robustness.
