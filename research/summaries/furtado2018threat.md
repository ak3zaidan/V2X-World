# Threat Analysis of the Security Credential Management System for Vehicular Communications
Matthew D. Furtado, Robert D. Mushrall, Hong Liu · IEEE International Conference on Technologies for Homeland Security 2018 · https://doi.org/10.1109/ths.2018.8574206 · relevance: high · basis: abstract

**Problem:** Threats to the US SCMS.
**Approach:** STRIDE threat modelling of SCMS main use cases with Microsoft Threat Modeling tool; mitigations matched to SCMS defences.
**Tools and scale:** Threat modelling tool.
**Results:** Threat list across six STRIDE categories with mitigations.
