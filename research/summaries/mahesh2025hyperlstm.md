# HyperLSTM for Anomaly Detection Model for VANET Security Using the VeReMi Extension Dataset
T. R. Mahesh, G. Gangadevi, Kritika Kumari Mishra, Ali Algarni, Oumaima Saidani, Adarsh Kumar · International Journal of Distributed Sensor Networks 2025 · https://doi.org/10.1155/dsn/6789771 · relevance: high · basis: abstract

**Problem:** Anomaly detection in VANETs.
**Approach:** HyperLSTM with dropout and overlapping windows.
**Tools and scale:** VeReMi Extension.
**Results:** 98% accuracy; MSE 0.0649.

- None stated.
