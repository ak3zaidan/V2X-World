# Monitoring Algorithm in Malicious Vehicular Adhoc Networks
S. Padmapriya, R. Valli, M. Jayekumar · 2020 International Conference on System, Computation, Automation and Networking (ICSCAN) 2020 · https://doi.org/10.1109/icscan49426.2020.9262314 · relevance: low · basis: abstract

**Problem:** Vehicular Adhoc Networks (VANETs) ensures road safety by communicating with a set of smart vehicles. VANET is a subset of Mobile Adhoc Networks (MANETs).
**Approach:** To overcome security threats, we propose Monitoring Algorithm that detects malicious nodes based on the pre-selected threshold value. The proposed Monitoring Algorithm not only detects malicious vehicles, but also isolates the malicious vehicles from the network.
**Tools and scale:** Vehicular setting (VANET/IoV/V2X). Not detailed in the catalogued abstract (no integrated traffic, radio and SCMS simulation identified); see the paper for setup and scale.
**Results:** The simulation result illustrated that the proposed Monitoring Algorithm outperforms the existing algorithms in terms of malicious node detection, network delay, packet delivery ratio and throughput, thereby uplifting the overall performance of the network.
