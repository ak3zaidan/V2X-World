# Calibrating Wireless AI via Meta-Learned Context-Dependent Conformal Prediction
Seonghoon Yoo, Sangwoo Park, Petar Popovski, Joonhyuk Kang, Osvaldo Simeone · IEEE Transactions on Signal Processing 2026 · https://doi.org/10.1109/tsp.2026.3650912 · relevance: low · basis: abstract

**Problem:** Modern software-defined networks, such as Open Radio Access Network (O-RAN) systems, rely on artificial intelligence (AI)-powered applications running on controllers interfaced with the radio access network.
**Approach:** To ensure that these AI applications operate reliably at runtime, they must be properly calibrated before deployment. A promising and theoretically grounded approach to calibration is conformal prediction (CP), which enhances any AI model by transforming it into a provably reliable set predictor that provides error bars for estimates and decisions.
