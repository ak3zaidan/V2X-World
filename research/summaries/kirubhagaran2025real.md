# Real-Time Intrusion Detection System for Automotive CAN Bus Using Machine Learning and Virtual Simulation
G Kirubhagaran, M. Prasanth, Kumar M Niranjan et al. · venue unknown 2025 · https://doi.org/10.1109/sennet64220.2025.11135991 · relevance: medium · basis: abstract

**Problem:** As cars are getting more connected and autonomous, the security for in-car communication has progressively become more crucial.
**Approach:** The CAN bus protocol, the vehicular communication bus among ECUs today, was initially designed with emphasis on real-time performance and reliability rather than security. In this proposed work, we present a real-time machine learning-powered Intrusion Detection System (IDS) for CAN bus networks with use of the Isolation Forest algorithm.
**Tools and scale:** Not stated in the abstract.
**Results:** The system is light, modular, and embeddable, and it provides an energy-efficient solution towards improving vehicular cybersecurity
