# Sim2HW: Modeling Latency Offset Between Network Simulations and Hardware Measurements
Johannes Späth, Max Helm, Benedikt Jaeger, Georg Carle · Proceedings of the 3rd GNNet Workshop on Graph Neural Networking Workshop 2024 · https://doi.org/10.1145/3694811.3697820 · relevance: high · basis: abstract

**Problem:** Simulation and hardware latency differ.
**Approach:** GNN using simulation data as input to predict hardware-measured latency.
**Tools and scale:** Hardware testbed dataset.
**Results:** MAPE 27.2%, MdAPE 19.8% on unseen topologies.
