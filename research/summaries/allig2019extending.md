# Extending the vehicular network simulator Artery in order to generate synthetic data for collective perception
Christoph Allig, Gerd Wanielik · Advances in Radio Science 2019 · https://doi.org/10.5194/ars-17-189-2019 · relevance: high · basis: full text

**Problem:** Cooperative perception data is hard to collect on real roads at realistic penetration rates.
**Approach:** Extends Artery/SUMO with longitudinal/lateral vehicle dynamics, lateral controller, probabilistic sensor models and a CPM service to generate synthetic CP data.
**Tools and scale:** Artery, SUMO, ITS-G5 CPM.
**Results:** Vehicle dynamics extensions evaluated; framework ready for CP studies.
**Limitations and future work (as stated by the authors):**
- Apply to cooperative perception investigation
- test sensor fusion methods and message formats
- source code not public.
**Overlap with our engine:** partial — synthetic V2X dataset generation from simulation, related to our benchmark direction, but no security labels.
**Novelty implications:** Synthetic CP data generation exists; security ground-truth labels remain open.
