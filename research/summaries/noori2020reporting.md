# Reporting Spectrum Misbehaviour using the IEEE 1609 Security Credential Management System
Hamed Noori, David G. Michelson, Kevin Henry · IEEE Vehicular Technology Conference 2020 · https://doi.org/10.1109/vtc2020-spring48590.2020.9129509 · relevance: high · basis: abstract

**Problem:** Reporting DSRC interference needs backhaul.
**Approach:** Clone the SCMS misbehaviour-reporting subsystem to a Spectrum Misbehaviour Authority; new message types for RSU-only and OBU reporting.
**Tools and scale:** Design; IEEE 1609 SCMS.
**Results:** Defines reports; SMA validates and warns.
**Limitations and future work (as stated by the authors):**
- None stated in abstract.
**Overlap with our engine:** partial — Uses SCMS misbehaviour reporting path, which our engine implements (MA).
**Novelty implications:** Extension of SCMS reporting to spectrum issues already proposed.
