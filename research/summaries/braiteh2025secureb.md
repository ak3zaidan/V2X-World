# Secure Group Key Dissemination Protocol in Cooperative Vehicular Platooning
Farah-Emma Braiteh, Francesca Bassi, Rida Khatoun · 2025 21th International Conference on Wireless and Mobile Computing, Networking and Communications (WiMob) 2025 · https://doi.org/10.1109/wimob66857.2025.11257457 · relevance: high · basis: abstract

**Problem:** Pseudonym changes in platoons cause legitimate members to be misidentified as attackers; platoon data needs protection.
**Approach:** Group-key authentication framework for platoons using post-quantum cryptography and Shamir secret sharing for key exchange, built on C-ITS PKI pseudonyms. (summarised from the abstract only)
**Tools and scale:** Scyther formal analysis; PLEXE (Veins/SUMO) simulation.
**Results:** Abstract reports protocol effectiveness; no numbers given.
