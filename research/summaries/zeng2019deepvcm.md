# DeepVCM: A Deep Learning Based Intrusion Detection Method in VANET
Yi Zeng, Mei-Kang Qiu, Dan Zhu, Zhihao Xue, Jian Xiong, Meiqin Liu · 2019 IEEE 5th Intl Conference on Big Data Security on Cloud (BigDataSecurity), IEEE Intl Conference on High Performance and Smart Computing, (HPSC) and IEEE Intl Conference on Intelligent Data and Security (IDS) 2019 · https://doi.org/10.1109/bigdatasecurity-hpsc-ids.2019.00060 · relevance: medium · basis: abstract

**Problem:** With the rapid development in smart vehicles, the security and privacy issues of the Vehicular Ad-hoc Network (VANET) have drawn significant attention. Devices in an On-Board Unit (OBU) access to the internet through the Vehicular Communication Module (VCM), hence a real-time and accurate intrusion detection method is favored to be applied in VCM.
**Approach:** In this paper, we present a Deep Learning (DL) based end-to-end intrusion detection method to automatically detect malware traffic for OBUs.
**Tools and scale:** The performance is compared with previous methods on a public dataset and a simulated real-life VANET dataset.
**Results:** Experimental results show that our method can attain a higher performance with a lower resources requirement.
