# Malicious Node Detection in VANETs via Enhanced DSR and ML
Palaniappan AN, J Pranav, S Shivamanikkavasakam, Santosh D. Kumar, R Gandhiraj · International Conference on Wireless Communications, Signal Processing and Networking (WiSPNET) 2024 · https://doi.org/10.1109/wispnet61464.2024.10532957 · relevance: medium · basis: abstract

**Problem:** Being vulnerable to various security threats like other wireless networks, Vehicular Ad-hoc Networks (VANETs) need an effective intrusion detection system to ensure security in VANETs.
**Approach:** This paper proposes an intrusion detection system for VANETs using machine learning techniques. The system is implemented in NetSim where a VANET is created with a malicious node causing blackhole/sinkhole attack.
**Tools and scale:** Not stated in the abstract.
**Results:** The models provide over 99% accuracy, precision, recall and F1-score in detecting malicious nodes, outperforming previous approaches.
**Limitations and future work (as stated by the authors):**
- The system is implemented in NetSim where a VANET is created with a malicious node causing blackhole/sinkhole attack.
- Once detected, the route through the malicious node is avoided in future transmissions.
**Overlap with our engine:** partial — same area (V2X/vehicular security or networking) with a narrower, mechanism-level focus.
**Novelty implications:** Does not remove any of our claims beyond its specific mechanism; we cannot claim to be first on that mechanism. The joint closed-loop traffic/radio/PKI evaluation with counterfactual ground truth remains open as far as this abstract shows.
