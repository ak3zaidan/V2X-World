# Adversarial Hallucination Engineering: Targeted Misdirection Attacks Against LLM Powered Security Operations Centers
Ashutosh Agarwal ·  2025 · https://doi.org/10.20944/preprints202512.0913.v1 · relevance: medium · basis: abstract

**Problem:** Poisoned RAG context can steer LLM SOC reasoning.
**Approach:** Adversarial Hallucination Engineering threat model, Hallucination Propagation Chains, CoTA defence.
**Tools and scale:** Fully synthetic RAG+LLM SOC simulator; three model scales.
**Results:** HIR 12.45% to 61.84% for 70B proxy as HPC size grows 0 to 5; misconfiguration 3.23% to 38.18%; CoTA cuts ASR by about 55%.
