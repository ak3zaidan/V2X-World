# VMGuard: Reputation-Based Incentive Mechanism for Poisoning Attack Detection in Vehicular Metaverse
Ismail Lotfi, Marwa Qaraqe, Ali Ghrayeb, Dusit Tao Niyato · IEEE Transactions on Vehicular Technology 2025 · https://doi.org/10.1109/tvt.2025.3543650 · relevance: medium · basis: abstract

**Problem:** The vehicular Metaverse represents an emerging paradigm that merges vehicular communications with virtual environments, integrating real-world data to enhance in-vehicle services. However, this integration faces critical security challenges, particularly in the data collection layer where malicious sensing IoT (SIoT) devices can compromise service quality through data poisoning attacks.
**Approach:** The security aspects of the Metaverse services should be well addressed both when creating the digital twins of the physical systems and when delivering the virtual service to the vehicular Metaverse users (VMUs). This paper introduces vehicular Metaverse guard (VMGuard), a novel four-layer security framework that protects vehicular Metaverse systems from data poisoning attacks.
**Tools and scale:** Car-Hacking/CAN dataset (mentioned in abstract)
**Results:** Ultimately, we validate our proposed model using comprehensive simulations.
