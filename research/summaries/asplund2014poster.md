# Poster: Securing vehicular platoon membership
Mikael Asplund · 2014 IEEE Vehicular Networking Conference (VNC) 2014 · https://doi.org/10.1109/vnc.2014.7013324 · relevance: high · basis: abstract

**Problem:** Vehicular platoons have the potential to bring considerable fuel-savings and increase traffic efficiency.
**Approach:** A key component for the next generation platoon systems is a secure membership component which can accommodate membership changes in a dynamic and potentially hostile environment. In this poster paper we analyse the conditions for creating a secure membership protocol which is resilient to attacks and faults in the communication protocols.
