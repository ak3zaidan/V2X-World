# Prediction of Packet Delivery Ratio Using Lasso Regression in Comparison with Linear Regression Algorithm for Multi Input Multi Output Network
V. Venu Gopal Reddy, S. Narendran · 2022 4th International Conference on Advances in Computing, Communication Control and Networking (ICAC3N) 2022 · https://doi.org/10.1109/icac3n56670.2022.10074219 · relevance: low · basis: abstract

**Problem:** The aim of the study is to predict the accurate Packet Delivery Ratio (PDR) using the dataset provided with the help of the machine learning technique Novel Linear and compared with Lasso regression algorithms.
**Approach:** Sklearn machine learning library in python is used to perform Regression with help of 10000 PDR values generated using python in which about 1 - 50 SNR (Signal to Noise Ratio) and its corresponding Packet Delivery Ratio (PDR) are obtained. Sample sizes of the two groups are 10 each.
**Tools and scale:** Mentioned in abstract: dataset.
**Results:** PDR of lasso regression is 96.56 % and PDR of Linear regression is 95.48 % for corresponding SNR is 4 db.
