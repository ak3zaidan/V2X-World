# Network Data Based Transfer Learning Failure Prediction Agent Pre-Trained Using Digital Twin
Mashboob Cheruvakkadu Mohamed, M. Masood, Imran Chowdhury Dipto, Renato Ambrosone, Gulmina Malik, S. Straullu, S. Bhyri, G. Galimberti, J. Pedro, A. Napoli, W. Wakim, V. Curri · International Conference on Optical Network Design and Modelling 2025 · https://doi.org/10.23919/ondm65745.2025.11029222 · relevance: low · basis: abstract

**Problem:** This paper describes the use of Transfer Learning (TL) using experimental data and a Machine Learning (ML) model pre-trained with a Digital Twin (DT) for the prediction of amplifier failures in optical networks.
**Approach:** Using GNPy, an open-source framework, amplifier failure conditions are simulated, creating the required training dataset for the ML model. Later, by implementing TL using optical transmission testbed network data, the model is able to capture realtime network fluctuations, thereby enabling it to distinguish network parameters variations due to any incoming failures from the regular network dynamics, thus enhancing the practical applicability of the model.
**Tools and scale:** Mentioned in abstract: dataset, simulated, testbed.
**Results:** The model is based on the Long Short-Term Memory (LSTM) ML Technique and is shown to achieve a TL accuracy of 99%, demonstrating the ability of the model to effectively predict failures. This method facilitates early identification and intervention, reduces service interruptions, and improves network reliability.
