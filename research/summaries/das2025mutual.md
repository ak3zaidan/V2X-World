# Mutual Authentication and Trust Establishment (MATE) Protocol in VANET Using Puncturable Pseudorandom Function (PPRF): MATE-PPRF
Priyanka Das, Sangram Ray, Mou Dasgupta, Saru Kumari et al. · IEEE transactions on intelligent transportation systems (Print) 2025 · https://doi.org/10.1109/tits.2025.3589123 · relevance: low · basis: abstract

**Problem:** Thus, to address the security concerns, it is a common practice to establish an authentication and key agreement protocol among the communicating entities that ensures to provide the essential security requirements.
**Approach:** Therefore, in this paper, we have proposed a trust-extended mutual authentication protocol for the VANET framework using a Puncturable Pseudorandom Function (PPRF).
**Tools and scale:** Not stated in the abstract beyond the above; no traffic simulator, radio stack or SCMS-scale deployment is described.
**Results:** VANET realizes interactive communication through wireless medium among Vehicle to Vehicle (V2V) and Vehicle to Infrastructure (V2I). The informal and formal security verification of our protocol proves that it provides comparably higher security than the existing schemes.
