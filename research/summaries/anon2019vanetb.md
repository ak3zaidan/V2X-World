# VANET and FANET under the Impact of the Security Attack
 · International Journal of Innovative Technology and Exploring Engineering 2019 · https://doi.org/10.35940/ijitee.i1062.0789s19 · relevance: medium · basis: abstract

**Problem:** The flying ad hoc network (FANET) is a distributed type of network in which nodes have the ability to join or leave the network at any time as and when needed.
**Approach:** FANET is the kind of ad-hoc network just like the Mobile ad-hoc network (MANET) and the Vehicular ad-hoc network (VANET). In our previous work a monitor mode technique is proposed for the detection of malicious nodes in Flying ad-hoc network (FANET).
**Tools and scale:** Not stated in the abstract.
**Results:** The ad- hoc network is unstable when malicious nodes are present in the network which create fake identities, so that security of the network is to be reduced.
