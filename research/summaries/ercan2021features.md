# New Features for Position Falsification Detection in VANETs using Machine Learning
Secil Ercan, Marwane Ayaida, Nadhir Messai · ICC 2021 - IEEE International Conference on Communications 2021 · https://doi.org/10.1109/icc42927.2021.9500411 · relevance: high · basis: abstract

**Problem:** Better features for position falsification detection.
**Approach:** Estimated angle of arrival and path-loss-based distance as new features; RF and k-NN classifiers.
**Tools and scale:** Public dataset (VeReMi).
**Results:** Improved classification metrics vs previous approaches.
**Limitations and future work (as stated by the authors):**
- None stated in abstract.
**Overlap with our engine:** partial — radio-derived features for MBD.
**Novelty implications:** Radio-layer features for position MBD exist.
