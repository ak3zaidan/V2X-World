# Extending Network Simulator ns-3 for Analyzing IoT Malware
Jun'ichiro Hara, Koichi Mouri, Eiji Takimoto · Proceedings of the 2024 13th International Conference on Networks, Communication and Computing 2024 · https://doi.org/10.1145/3711650.3711661 · relevance: low · basis: abstract

**Problem:** Dynamic analysis of IoT malware requires an Internet connection to observe the original behavior of the malware.
**Approach:** However, when performing dynamic analysis, an environment that uses real external servers may be complicit in the attack. In dynamic analysis without an Internet connection, we sometimes simulate an external server with which the malware communicates.
