# Platoon Handover Authentication in 5G-V2X : IEEE CNS 20 Poster
Guanjie Li, Chengzhe Lai · 2020 IEEE Conference on Communications and Network Security (CNS) 2020 · https://doi.org/10.1109/cns48642.2020.9162271 · relevance: low · basis: abstract

**Problem:** In 5G-Vehicle to Everything (5G-V2X) network, the signaling storm may incur as platoon moves through in such ultra-dense network (UDN) of base stations since masses of vehicles in the platoon execute the handover authentication simultaneously.
**Approach:** In this poster, we propose an efficient platoon authentication handover scheme by integrating Software Defined Network (SDN) and Aggregated Message Authentication Codes (AMACs) techniques in 5G-V2X network to reduce handover signaling overhead and communication delay during authentication.
