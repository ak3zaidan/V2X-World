# Design and Validation of a Secure and Context-Aware Vehicular Ad Hoc Network (VANET) Framework Using Trust-Based Multiobjective Analysis
P. Jadhav, D. Bhoyar · International Journal of Computer Networks And Applications 2026 · https://doi.org/10.22247/ijcna/2026/45 · relevance: high · basis: full text

**Problem:** Fragmented VANET security functions (trust, IDS, key exchange, QoS, integrity).
**Approach:** QRVA: probabilistic trust graph, federated IDS, simulated quantum-resilient key exchange, multi-metric evaluation and Merkle-aggregated event validation with cross-layer feedback.
**Tools and scale:** Veins, SUMO, OMNeT++, VeReMi misbehaviour dataset.
**Results:** Detection accuracy 93.2-94.8%, federated detection 95.9-96.4%, false-trust propagation 1.5-1.8%, lattice key establishment 2.1 ms, 17.2 MB overhead per 1000 vehicles per hour.
