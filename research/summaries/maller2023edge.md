# Edge computing in the loop simulation framework for automotive use cases evaluation
Levente Márk Maller, Péter Suskovics, László Bokor · Wireless Networks 2023 · https://doi.org/10.1007/s11276-023-03432-3 · relevance: medium · basis: abstract

**Problem:** Edge architectures provide local, decentralized services, enabling balancing network traffic and distributing hardware resources.
**Approach:** Later, many new use cases can be implemented by combining the advantages of the edge computing concept with the services of 5G systems. One of the biggest beneficiaries of this could be the Vehicle-to-Cloud (V2C) technology, where it is necessary to efficiently process large amounts of data resulting from Vehicle-to-Everything communication (V2X) services.
