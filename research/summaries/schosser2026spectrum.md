# Spectrum Anomaly Detection in OFDMA Systems: Simulation Framework and Benchmark Dataset
Anton Schösser, Mohammadhadi Salehi, Sinuo Ma et al. · arXiv 2026 · https://arxiv.org/abs/2606.02102 · relevance: low · basis: abstract

**Problem:** Wireless connectivity underpins modern society and industry, enabling critical applications such as 5G ultra-reliable low-latency communication (URLLC) for industrial automation.
**Approach:** To address this, we present a benchmark dataset for spectrum anomaly detection in orthogonal frequency-division multiplexing access (OFDMA) systems, a core technology for 5G and beyond. These anomalies are simulated in an industrial factory environment using a versatile open-source framework developed and published as part of this work, enabling extensibility to new scenarios and interference types.
