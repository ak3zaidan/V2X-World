# Digital Twins for Security Automation
K. Hammar, R. Stadler · IEEE/IFIP Network Operations and Management Symposium 2023 · https://doi.org/10.1109/noms56928.2023.10154288 · relevance: low · basis: abstract

**Problem:** We present a novel emulation system for creating high-fidelity digital twins of IT infrastructures.
**Approach:** The digital twins replicate key functionality of the corresponding infrastructures and allow to play out security scenarios in a safe environment. We show that this capability can be used to automate the process of finding effective security policies for a target infrastructure.
**Tools and scale:** Mentioned in abstract: emulation, simulations.
**Results:** This closed-loop learning process executes iteratively and provides continuously evolving and improving security policies. Our results show that the digital twin provides the necessary evaluative feedback to learn near-optimal intrusion response policies.
