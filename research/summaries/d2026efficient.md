# An Efficient Blockchain-Enabled Architecture for Secure Vehicle-to-Vehicle Communication
Ashmita D, Samyuktha V, S. S, Megha S. Kumar · 2026 Control Instrumentation Systems Conference (CISCON) 2026 · https://doi.org/10.1109/ciscon71603.2026.11709095 · relevance: medium · basis: abstract

**Problem:** Vehicles can communicate critical safety messages in real time through Vehicular Ad-hoc Networks (VANETs). However, these networks are affected by security, privacy, and scalability challenges, mainly due to the centralized approach of the Public Key Infrastructure (PKI) systems.
**Approach:** To address these challenges, this paper presents a secure and efficient Vehicle-to-Vehicle (V2V) communication system based on Blockchain and Ethereum Smart Contracts.
**Tools and scale:** Not stated in the abstract; appears to be analytical/cryptographic or review work.
**Results:** Performance results show that RSA has faster verification time compared to ECC, making RSA more efficient for real-time V2V messaging. Furthermore, the proposed system uses InterPlanetary File System (IPFS) for efficient storage of data in the system, reducing the storage load of the blockchain.
