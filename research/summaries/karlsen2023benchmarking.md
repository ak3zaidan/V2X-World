# Benchmarking Large Language Models for Log Analysis, Security, and Interpretation
Egil Karlsen, Xiao Luo, Nur Zincir-Heywood, Malcolm Heywood · arXiv 2023 · https://arxiv.org/abs/2311.14519 · relevance: medium · basis: abstract

**Problem:** LLM capability for security log analysis.
**Approach:** Benchmark 60 fine-tuned models; LLM4Sec pipeline.
**Tools and scale:** Six web and system log datasets.
**Results:** DistilRoBERTa average F1 0.998.
