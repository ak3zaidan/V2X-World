# 3GPP NR V2X Mode 2d: Analysis of Distributed Scheduling for Groupcast using ns-3 5G LENA Simulator
Thomas Fehrenbach, Luis Omar Ortiz Abrego, Cornelius Hellge, Thomas Schierl, Jörg Ott · 2025 IEEE Conference on Standards for Communications and Networking (CSCN) 2025 · https://doi.org/10.1109/cscn67557.2025.11230706 · relevance: high · basis: full text

**Problem:** NR V2X groupcast scheduling for platooning.
**Approach:** Evaluates Mode 2d distributed group scheduling in ns-3 5G-LENA.
**Tools and scale:** ns-3 5G-LENA.
**Results:** Mode 2d meets reliability, latency and data rate needs for platooning.
