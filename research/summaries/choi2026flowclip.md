# FlowCLIP: Contrastive Pretraining Using Domain Names for Encrypted Traffic Classification
E. Choi · arXiv.org 2026 · https://arxiv.org/abs/2606.17746 · relevance: low · basis: abstract

**Problem:** Network traffic classification enables website fingerprinting, intrusion detection, and quality of service management.
**Approach:** We introduce FlowCLIP, a contrastive pretraining framework for learning traffic representations using only side-channel features: packet inter-arrival times, packet sizes, and packet directions.
**Tools and scale:** Not stated in the abstract.
**Results:** Through these evaluations, we show that domain names can be used directly for traffic representation learning without defining traffic classes.
