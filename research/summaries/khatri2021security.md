# Security Issues with In-Vehicle Networks, and Enhanced Countermeasures Based on Blockchain
N. Khatri, R. Shrestha, S. Nam · Electronics 2021 · https://doi.org/10.3390/electronics10080893 · relevance: low · basis: abstract

**Problem:** Modern vehicles are no longer simply mechanical devices. Connectivity between the vehicular network and the outside world has widened the security holes that hackers can use to exploit a vehicular network.
**Approach:** However, these protocols were not designed with security in mind. In this paper, we investigate the security vulnerabilities with in-vehicle network protocols such as CAN, automotive Ethernet, and FlexRay.
