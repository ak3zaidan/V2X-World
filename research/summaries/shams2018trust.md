# Trust aware support vector machine intrusion detection and prevention system in vehicular ad hoc networks
Erfan A. Shams, Ahmet Rizaner, Ali Hakan Ulusoy · Computers &amp; Security 2018 · https://doi.org/10.1016/j.cose.2018.06.008 · relevance: medium · basis: abstract

**Problem:** As a mean to improve safety and convenience on the road, Vehicular Ad Hoc Networks (VANETs) provide various advantages to passengers. However, considering that it is a wireless ad hoc type network, it is usual to see numerous security exploits present in the environment.
**Approach:** In this paper, we propose a complete IDS in VANET using the combination of modified promiscuous mode for data collection and Support Vector Machine (SVM) for data analysis to establish a shared trust value for every vehicle on the network as Trust Aware SVM-Based IDS (TSIDS).
