# Detection of Multiple Malicious Nodes Using Entropy for Mitigating the Effect of Denial of Service Attack in VANETs
Sushil Kumar, Kulwinder Singh Mann · 2018 4th International Conference on Computing Sciences (ICCS) 2018 · https://doi.org/10.1109/iccs.2018.00018 · relevance: medium · basis: abstract

**Problem:** This paper presents the algorithm for the detection of jamming attack of Denial of Service (DoS) security attacks in VANETs. Since VANETs disseminate life saving information, so all the security attacks need to be detected well in time.
**Approach:** They are not capable for sending critical information well in time to the vehicles in the network. In the existing packet detection algorithms, single malicious nodes were detected and that node was isolated from the routing network.
