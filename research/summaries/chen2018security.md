# A Security Scheme of 5G Ultradense Network Based on the Implicit Certificate
Zhonglin Chen, Shanzhi Chen, Hui Xu et al. · Wireless Communications and Mobile Computing 2018 · https://doi.org/10.1155/2018/8562904 · relevance: low · basis: abstract

**Problem:** The ultradense network (UDN) is one of the most promising technologies in the fifth generation (5G) to address the network system capacity issue.
**Approach:** In this paper, we proposed a new security based on implicit certificate (IC) scheme; the scheme solves the security problem among the access points (APs) in a dynamic APs group (APG) and between the AP and user equipment (UE).
**Tools and scale:** The simulation on network bandwidth evaluation is also conducted to prove the efficiency of the solution.
**Results:** No quantitative results stated in the abstract.
**Limitations and future work (as stated by the authors):**
- However, the security of the 5G UDN is still in its infancy, and the data communication security among the network entities is facing new challenges.
