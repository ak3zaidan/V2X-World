# Leveraging Lightweight Machine Learning for RF Jamming Detection in Mobile ad-hoc Networks: A Three-Tier Edge-Fog-Cloud Computing Approach
Hakim Bessouf, Abderrahmane Baadache, Fouzi Semchedine · Cybernetics and Information Technologies 2026 · https://doi.org/10.2478/cait-2026-0005 · relevance: medium · basis: abstract

**Approach:** Three-tier edge-fog-cloud ML framework with priority-based task allocation.
**Tools and scale:** MANET (not vehicle-specific).
