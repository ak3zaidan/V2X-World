# Multi-Radio-Based Vehicle Pseudonym Association
Pierson Yieh, Aaron Otis, Andrew R. Li, Sean Bayley, Atticus Liu, Chin Chao, Daniel Kim, Bruce DeBruhl, Yu Seung Kim · 2019 IEEE 90th Vehicular Technology Conference (VTC2019-Fall) 2019 · https://doi.org/10.1109/vtcfall.2019.8891278 · relevance: medium · basis: abstract

**Problem:** Tracking vehicles across pseudonym changes using other radios.
**Approach:** VETing: secondary radios with long-term IDs de-anonymise V2X pseudonyms.
**Tools and scale:** Simulator with listener network in a city.
**Results:** High-precision path reconstruction.
