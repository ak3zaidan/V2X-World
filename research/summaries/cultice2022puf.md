# PUF-Based Post-Quantum CAN-FD Framework for Vehicular Security
Tyler Cultice, Himanshu Thapliyal · Information 2022 · https://doi.org/10.3390/info13080382 · relevance: high · basis: full text

**Problem:** CAN payloads too small for PQ crypto; CAN-FD enables it.
**Approach:** PUF-PQC-CANFD framework using PUFs and SIDH for authentication with reduced messages.
**Tools and scale:** Analytical bus message evaluation up to 100 ECUs.
**Results:** 25-94% fewer messages than pre-quantum frameworks, 99% fewer than PQ frameworks.
**Limitations and future work (as stated by the authors):**
- SIDH broken by recent attacks
- replace with e.g. CRYSTALS-Kyber
- hardware implementation still to be done
**Overlap with our engine:** none — In-vehicle bus.
**Novelty implications:** None.
