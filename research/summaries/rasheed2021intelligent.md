# Intelligent super-fast Vehicle-to-Everything 5G communications with predictive switching between mmWave and THz links
Iftikhar Rasheed, Fei Hu · Vehicular Communications 2021 · https://doi.org/10.1016/j.vehcom.2020.100303 · relevance: medium · basis: abstract

**Problem:** Abstract With the incoming of 5G communications, Vehicular Networks have the hope to achieve ultra-high data transmission rate with extremely low end-to-end delay. However, the dynamic nature of transportation traffic and increased data bandwidth demands are the major obstacles to achieve high transmission rate in Vehicular-to-Anything (V2X) Networks.
**Approach:** To overcome these obstacles, this paper presents a novel Software Defined Networking (SDN)-controlled and Cognitive Radio (CR)-enabled V2X routing approach to achieve ultra-high data rate, by using predictive V2X routing that supports the intelligent switching between two 5G technologies: millimeter-wave (mmWave) and terahertz (THz). By using these three intelligent designs approaches, we are able to achieve ultrahigh- rate and minimized transmission delay for short-range (in THz bands) and middle-range (in mmWave) communications.
**Tools and scale:** Mentioned in abstract: 5G. (From the abstract only.)
**Results:** To improve the network management, Road Side units (RSUs) are used to segregate the V2X network into different clusters. Our intelligent V2X is based on three features enabled machine learning approach: (1) To predict future 3D positions of the vehicles in the Cluster Heads (CHs) using Deep Neural Network with Extended Kalman Filter (DNN-EKF) algorithm for real-time, high-resolution prediction. (2) For THz communications, 0.3 THz to 3 THz band is selected for short-distance super-fast data transmissions.
