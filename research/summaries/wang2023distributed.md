# Distributed Fault Detection Scheme for Intelligent Connected Vehicles in a Zero-trust Environment
Yongshi Wang, Yuhong Na, Shuiqing Xu, Darong Huang · 2023 2nd Conference on Fully Actuated System Theory and Applications (CFASTA) 2023 · https://doi.org/10.1109/cfasta57821.2023.10243267 · relevance: medium · basis: abstract

**Problem:** This paper investigates the analysis and design of distributed fault detection for $\mathcal{L}_{2}$ observer-based intelligent connected vehicles in a zero-trust environment.
**Approach:** Intelligent connected vehicles can improve traffic efficiency, but the system can be unreliable due to network security issues. Fault detection of intelligent connected vehicles is performed by introducing a zero-trust paradigm.
