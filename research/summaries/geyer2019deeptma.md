# DeepTMA: Predicting Effective Contention Models for Network Calculus using Graph Neural Networks
Fabien Geyer, Steffen Bondorf · IEEE INFOCOM 2019 - IEEE Conference on Computer Communications 2019 · https://doi.org/10.1109/infocom.2019.8737496 · relevance: high · basis: abstract

**Problem:** Tandem Matching Analysis in network calculus finds tight delay bounds but takes hours.
**Approach:** DeepTMA: a GNN predicts the best contention model per location and feeds it back to network calculus, keeping bounds provably valid.
**Tools and scale:** Wired networks of aggregate schedulers.
**Results:** Maximum relative error below 6% vs TMA with nearly constant execution time.
**Limitations and future work (as stated by the authors):**
- None stated in the abstract.
**Overlap with our engine:** partial - learned acceleration of formal network analysis (direction 3), wired.
