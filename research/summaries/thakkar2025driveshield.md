# DriveShield: FL-Based Framework for Privacy Preserving and Jamming Attack Detection in V2X Communication Underlying 6G
Dhyey Thakkar, P. Tandel, Aparna Kumari · 2025 IEEE 101st Vehicular Technology Conference (VTC2025-Spring) 2025 · https://doi.org/10.1109/vtc2025-spring65109.2025.11174289 · relevance: medium · basis: abstract

**Problem:** In this paper, we introduce DriveShield: a decentralized framework based on Federated Learning (FL) for real time jamming attack detection in VANETs under 6G communications.
**Approach:** The local Feedforward Neural Network (FNN) trained on each client is aggregated by the popular Federated Averaging (FedAvg) approach and achieves a global accuracy around 83%, and reaches a peak of 87% across the training rounds. In order to preserve data privacy and integrity, the integration of blockchain and the InterPlanetary File System (IPFS) is used to make tamper resistant, secure model weight transfers.
**Tools and scale:** Mentioned in abstract: 5G, blockchain
**Results:** Performance evaluation shows that 6G-THz communication has better latency performance than 5g uRLLC, as well as better transaction scalability using IPFs.
