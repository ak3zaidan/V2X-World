# Algorithms and Analysis for Optimizing the Tracking Performance of Cyber Attacked Sensor-Equipped Connected Vehicle Networks
Zisheng Wang, Rick S. Blum · IEEE Transactions on Information Forensics and Security 2021 · https://doi.org/10.1109/tifs.2021.3122070 · relevance: medium · basis: abstract

**Problem:** Sensor-equipped connected vehicle networks (SECVNs) have the potential to enable substantially safer driving by improved object tracking, which is an important basic building block in SECVNs.
**Approach:** Unfortunately, cyber-attacks on SECVNs pose a very serious threat which could lead to unacceptable outcomes, including fatalities. Recently there has been increasing focus on malicious attack detection and mitigation in SECVNs, and some of this work has considered attacks on sensor data to impact object tracking.

**Limitations and future work (as stated by the authors):**
- Unfortunately, low complexity mitigation approaches which do not compromise performance are lacking.
- However, the complexity of this new approach is dramatically lower than the best existing published low complexity approach, which provides performance which is substantially inferior to that provided by the new approach.
