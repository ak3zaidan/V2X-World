# Trusted Opportunistic Routing Based on Node Trust Model
Bing Su, Chenhui Du, Juan Huan · IEEE Access 2020 · https://doi.org/10.1109/access.2020.3020129 · relevance: medium · basis: abstract

**Problem:** In vehicular ad hoc networks, opportunistic routing can effectively improve the reliability and throughput. However, opportunistic routing also has security issues.
**Approach:** In this paper, a trust model based on node behavior is proposed for solving the problem of malicious nodes in the opportunistic routing and forwarding candidate set. The proposed trust model uses pruning and filtering mechanisms to remove malicious suggestions,and uses dynamic weight calculation methods to combine direct trust and indirect trust when calculating the comprehensive trust value, which can screen and filter low-trust nodes in the network.
**Tools and scale:** Car-Hacking/CAN dataset (mentioned in abstract)
**Results:** Extensive simulation results represent that the algorithm can significantly improve the network performance and reduce the interference of malicious nodes to the network system.
