# Enhancement of Chatbot Conversation for Network Troubleshooting by Combining LLM and System Log Analysis
Kazuma Hashimoto, Hiroki Oyoshi, Manato Fujimoto, Shingo Ata · 2025 25th Asia-Pacific Network Operations and Management Symposium (APNOMS) 2025 · https://doi.org/10.23919/apnoms67058.2025.11181452 · relevance: medium · basis: abstract

**Problem:** Chatbots for network troubleshooting depend on user literacy.
**Approach:** LLM directly analyses device system logs with preprocessing.
**Tools and scale:** Llama model.
**Results:** 86% analysis accuracy; preprocessing to essential information is crucial.
