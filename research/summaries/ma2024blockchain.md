# A Blockchain-Based Secure Distributed Authentication Scheme for Internet of Vehicles
Zhan-Fei Ma, Jing Jiang, Hui Wei, Bisheng Wang et al. · IEEE Access 2024 · https://doi.org/10.1109/access.2024.3409361 · relevance: low · basis: abstract

**Problem:** However, because of the peculiar structure of IoV, current authentication schemes heavily rely on Road Side Units (RSUs).
**Approach:** Based on this, this paper proposes a blockchain-based secure distributed authentication scheme for IoV. Second, in the IoV authentication process, smart contract technology is used to achieve automatic triggering of the authentication process, and an optimized Practical Byzantine Fault Tolerant Consensus (PBFT) algorithm is designed to add the authentication information to the blockchain ledger so that the authentication results can be reused.
**Tools and scale:** Not stated in the abstract beyond the above; no traffic simulator, radio stack or SCMS-scale deployment is described.
**Results:** An excessive number of RSUs will make it difficult to synchronize updates, which will make system authentication inefficient overall and prevent the reuse of authentication results. First, data processing and storage are decentralized to the edge of the network to reduce the communication delay and response time with the trusted authority (TA).

**Novelty implications:** Leaves open how such schemes behave inside a full SCMS with realistic traffic and radio load; it does not rule out any candidate direction.
