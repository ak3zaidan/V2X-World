# Asynchronous Federated Learning for Intrusion Detection in Vehicular Cyber-Physical Systems
Sunitha Safavat, D. Rawat · Conference on Computer Communications Workshops 2023 · https://doi.org/10.1109/infocomwkshps57453.2023.10225917 · relevance: medium · basis: abstract

**Problem:** In recent years, development in IoV technologies has reached more promising progress.
**Approach:** IoV technology helps vehicles interact and exchange information between public networks and the surrounding environment, which reduces road congestion. In order to protect the information from attack and to provide efficient data transmission, this paper proposes secure federated learning for a vehicular cyber-physical system using an Inter-polated public key and private key-ROTation (IPP-ROT)-based Elliptic Curve Cryptography (ECC) and Fed Buff: Federated Learning with Buffered Asynchronous Aggregation based Log Sigmoid Multi-Layer Perceptron (FB-FL-BAA-LSMLP) techniques.
**Tools and scale:** Mentioned in abstract: ECC
**Results:** At last, the performance of the proposed method is verified by comparing it with the existing techniques, and the results show better performance than the other methods.
