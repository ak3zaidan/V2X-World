# The ready-made scenarios the Studio's picker offers, in this order.
#
# One file name per line (relative to this folder); a line starting with "##" starts a heading;
# "#" is a comment. The engine's `scenario.list` reads this file when the scenario it was
# opened on is in this folder (crates/v2xw-server/src/live.rs, `preset_entries`). Every other
# file here is still a scenario that loads by path — the study, test and benchmark files — it
# is just not offered in the picker. The names and one-line descriptions shown are each file's
# `meta.name` and `meta.description`.
#
# None of them is tied to a place: the picker chooses the scenario first and then the city it
# runs on (worlds/cities.yaml; `v2xw run <file> --city <id>`). A file's `city` is only its
# default. The cities themselves are not scenarios, so there is no "other cities" group: every
# scenario here runs on Portland, Berlin or any of the library's US cities.
